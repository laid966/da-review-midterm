📝 题型预判与作答策略

选择 / 判断 约 30–40%

背"定义 + 反例"。重点：相关≠因果、过拟合、UNION vs UNION ALL、LSH 参数方向、precision/recall。

简答 / 对比 约 25–30%

准备 10 组对比模板：4 种 JOIN、SVD vs CUR、层次 vs k-means、user-user vs item-item、InfoVis vs SciVis……

计算 约 25–35%

只考这几类：Jaccard/Min-Hash、LSH 概率 1−(1−sʳ)ᵇ、混淆矩阵指标、k-means 一轮迭代、SVD 低秩近似误差。练到 3 分钟算完。

SQL 写查询 约 10–15%

背模板：JOIN + GROUP BY + HAVING；IN/EXISTS 嵌套；LEFT JOIN 找"没有"。写完检查聚合列与 GROUP BY。

计算题给步骤分：公式 → 代入 → 中间结果 → 结论。数字算错但公式对了也能拿大半。

记忆口诀（全课）：导论看陷阱，SQL 看语义，相似看概率，学习看指标，聚类看距离，降维看分解。

📐 公式总表（按讲次）

模块公式说明 / 考点
L3 JaccardJ(A,B) = |A ∩ B| / |A ∪ B|集合相似度，0–1。文档相似度用它（不是欧氏距离）。
Pr[ h(C₁) = h(C₂) ] = J(C₁,C₂)Min-Hash 的核心性质：单个哈希函数命中概率 = Jaccard。必考证明/解释。
L3/L4 LSHP = 1 − (1 − sʳ)ᵇb 个 band、每 band r 行，相似度 s 的两个文档成为候选对的概率。
s* ≈ (1/b)^(1/r)S-curve 的阈值近似位置；b↑ 阈值↓（召回↑），r↑ 阈值↑（精度↑）。
AND: p → pʳ ｜ OR: p → 1 − (1−p)ᵇr 次 AND 压低下概率，b 次 OR 抬高上概率，拼起来就是陡峭 S-curve。
L4 距离的 LSHP[同桶] = 1 − θ/π余弦距离 + 随机超平面。θ=π/2 时 P=0.5，即"距离阈值 0.5"。
P[同桶] ≥ 1 − d/a欧氏距离 + 直线分桶（桶宽 a），前提 d < a/2。a 越大越容易同桶。
L5 评价指标Accuracy = (TP+TN) / (TP+FP+FN+TN)类别不平衡时会"虚高"，是经典陷阱。
Precision = TP / (TP + FP)"说是正例的里面有多少真是"——查准率。
Recall = TP / (TP + FN)= Sensitivity，查全率；把阈值降低可以刷到 100% 但 Precision 崩。
Specificity = TN / (TN + FP)负类召回。
F₁ = 2·P·R / (P + R)调和平均，偏向较小的一方。
IoU = TP / (TP + FP + FN)= |A∩B| / |A∪B|；mIoU 是各类 IoU 的均值（分割任务）。
L6 聚类J = ∑ᵢ ∑_{x∈Cᵢ} ‖x − μᵢ‖²k-means 目标函数（SSE）；每轮"分配 + 更新质心"单调不增。
2d + 1 个值BFR 用 (N, SUM, SUMSQ) 概括一个簇，d 维 → 2d+1。考点：为什么内存 O(簇数) 而非 O(点数)。
L7 降维A = U Σ Vᵀm×n = (m×r)(r×r)(r×n)。U、V 列/行正交，Σ 对角奇异值降序。
Aₖ = Uₖ Σₖ Vₖᵀ取前 k 个奇异值/向量 = 最优 rank-k 近似（Frobenius 范数意义下）。
‖A − Aₖ‖_F = √(σ²_{k+1} + … + σ²_r)低秩近似误差 = 丢掉的那些奇异值平方和开根。最爱考的计算。
q_concept = q · V把新查询映射到"概念空间"，再算相似度。

🔀 必背概念对照（对比题模板）

易混对区别一句话
相关 Correlation vs 因果 Causation相关只是"数值同向变化"；因果需要满足"改 X 会导致 Y 变"。相关可由因果、共同原因（confounder）、纯巧合（spurious）三种原因造成。
欠拟合 Underfitting vs 过拟合 Overfitting模型太简单（训练/测试都差）vs 模型太复杂（训练好、测试差）。前者加复杂度，后者加数据/正则/简化。
Data Mining vs Machine Learning vs Visualization挖模式（描述）vs 建模型做预测（预测）vs 用图讲清结论（沟通）。
INNER JOIN vs OUTER JOININNER 丢不匹配行；LEFT/RIGHT/FULL 保留一侧/两侧的"孤儿行"，缺失列补 NULL。
UNION vs UNION ALLUNION 去重（集合语义），UNION ALL 不去重（多重集语义，更快）。
WHERE vs HAVINGWHERE 在分组前过滤元组；HAVING 在 GROUP BY 之后过滤"组"。
Min-Hash vs LSHMin-Hash 把"长集合"压成"短签名"（保相似度）；LSH 把"签名"分桶，只比较可能相似的对（省计算）。两者是流水线的两步。
监督 vs 无监督有标签学映射（分类/回归）vs 无标签找结构（聚类/降维）。
Precision vs Recall查得准（报的里面真有多少）vs 查得全（真的里面抓到多少）。此消彼长，用 F₁ 折中。
层次聚类 vs k-means层次：不需要 k、给树状图、O(N²) 级；k-means：需要 k、快、对初始化敏感、只适合球形簇。
Single link vs Complete link单链用"最近一对点"距离（会 chaining 拉长条），全链用"最远一对点"（倾向紧凑球）。
BFR vs CUREBFR 假设簇是"轴对齐高斯"（用均值/方差概括）；CURE 用"多个代表点 + 收缩"处理任意形状，两遍扫描。
SVD vs CURSVD 最优但 U/V 是"抽象概念"，不可解释、稠密；CUR 用真实的行列，易解释、稀疏、近似误差更大。
PCA vs SVD本质同一件事：PCA = 对中心化后的数据做 SVD，主成分 = V 的列。
InfoVis vs SciVis信息可视化处理抽象数据（金融、社交）；科学可视化处理有物理空间坐标的数据（流体、医学）。
基于内容 vs 协同过滤用物品自身特征画像（无需他人数据，但有冷启动特征难题）vs 用"别人的评分"（无需特征，但稀疏/冷启动）。
User-user vs Item-item CF找相似用户推荐他喜欢的 vs 找相似物品（更稳定，物品数常远小于用户数）。
GD vs SGD全量梯度（稳、慢）vs 单样本/小批量（快、抖、能跳出局部）。
BatchNorm vs LayerNorm按 batch 维统计 vs 按单样本特征维统计（与 batch 大小无关，适合序列）。
Pooling vs Stride池化降采样并带来平移不变性；stride 是卷积自己跳着走。都降分辨率，但池化无可学习参数。

🔢 数字与默认参数（选择题最爱）

  • L3：文档去重例子 N = 100 万；示例参数 50 个哈希函数、r = 5、b = 10；2-shingle 例：D = abcab → {ab, bc, ca}。
  • L4：余弦 LSH 用随机超平面（random hyperplanes）；欧氏 LSH 用随机直线 + 桶宽 a。
  • L5：AlexNet（2012）5 个卷积层 + 2 个全连接层；Xavier 初始化配 tanh；Adam 是最常用的自适应方法。
  • L6：BFR 每个簇用 2d+1 个值；CURE 两遍扫描（pass 1 抽样聚类、pass 2 全量分配）。
  • L7：SVD 中 U 是 "user-to-concept"，Σ 是"概念强度"，Vᵀ 是 "concept-to-movie"。
  • L9（拓展）：Netflix 数据 1 亿评分 / 48 万用户 / 17770 部电影；冠军 RMSE 0.8563，全局均值基线 1.1296。

✍️ 三类题的作答模板

对比题：三段式

①各给一句定义 → ②列出 2–3 个维度上的差异（输入/输出、复杂度、假设、优缺点）→ ③一句"所以该用谁"。

计算题：四步

①写公式（拿公式分）→ ②代数值 → ③中间结果写清楚（阅卷看步骤）→ ④结论带单位/解释（比如"约 99.96%，即几乎所有相似对都被找到"）。

SQL 题：先写骨架再补细节

SELECT … FROM … JOIN … ON … WHERE … GROUP BY … HAVING … ORDER BY …；写完检查：聚合列是否都在 GROUP BY 里、NULL 会不会被漏掉（要"没有"的记录用 LEFT JOIN + IS NULL）。

记忆口诀：Jaccard 交集比并集，MinHash 概率等于它，LSH 一带一概率，1 减 (1 减 s 的 r 次) 的 b 次方；精确率看报出的，召回率看漏掉的，F1 取调和；SVD 三个矩阵，U 是概念、Σ 是强弱、V 是物品。

模拟卷（60 分钟・可折叠答案）Mock Exam真题风格

一、选择题（每题 2 分，共 36 分）

Q1. 研究显示"冰淇淋销量"与"溺水人数"高度相关。最合理的结论是？

答案：D

A. 吃冰淇淋导致溺水　B. 溺水导致人们买冰淇淋　C. 这是纯随机巧合，无法解释　D. 存在共同原因（气温/夏季），属于"相关不等于因果"

相关可由三种原因造成：X→Y、Y→X、共同的第三变量 Z（confounder），也可纯属巧合（spurious correlation）。

Q2. 某模型训练集误差 2%，测试集误差 28%，最可能的问题是？

答案：B 过拟合（overfitting）：模型过于"贴合"训练数据。对策：更多数据、正则化、降低模型复杂度、早停。

Q3. 表 Students 有 3 行，其中 1 行 gpa 为 NULL。SELECT COUNT(*), COUNT(gpa) FROM Students 的结果是？

答案：COUNT(*) = 3，COUNT(gpa) = 2。

COUNT(*) 数行；COUNT(列) 忽略 NULL。同理 SUM/AVG/MIN/MAX 都跳过 NULL（AVG 是"非空值的平均"，不是把 NULL 当 0）。

Q4. 对 R 和 S 做笛卡尔积（无连接条件），R 有 4 行、S 有 5 行，结果有多少行？

答案：20 行。

JOIN 的语义是"先做笛卡尔积，再用 ON/WHERE 过滤"，理解这一点就能解释为什么漏写连接条件会得到爆炸的行数。

Q5. UNION 与 UNION ALL 的差别是？

答案：UNION 做集合语义（去重），UNION ALL 保留重复（多重集语义）。

课件强调 SQL 默认是 multiset 语义：SELECT 不去重（要 DISTINCT）、UNION ALL 不去重。UNION 因为要去重通常更慢。

Q6. 想"按系分组后，只保留平均分大于 80 的系"，应该用哪个子句？

答案：HAVING

WHERE 在分组之前过滤行，不能用于聚合结果；HAVING 在 GROUP BY 之后过滤组。完整写法：SELECT dept, AVG(gpa) FROM Students GROUP BY dept HAVING AVG(gpa) > 80。

Q7. Shingling 这一步的目的是？

答案：把文档转换为 k-shingle 集合（长度 k 的连续 token 序列），从而可以用集合相似度（Jaccard）比较两篇文档。

k 太小时常见短语会误判相似（如 the, and），k 太大则对改动过于敏感；课件例：k=2，D=abcab → {ab, bc, ca}（相邻 k 个字符）。

Q8. 用 100 个 Min-Hash 函数得到签名，两文档有 62 个位置相同。估计的 Jaccard 相似度是？

答案：0.62（62/100）。签名相同位置的比例就是 Jaccard 的无偏估计，哈希函数越多估计越准。

Q9. LSH 中增大 band 数 b（r 不变），S-curve 会怎样变化？

答案：阈值左移（变小）→ 更多对成为候选 → 召回率↑、候选集变大、精确率可能↓。

因为 P = 1 − (1 − sʳ)ᵇ：b 增大使同一 s 下 P 更大。反之增大 r（每 band 行数）会抬高阈值、让曲线更陡。

Q10. 一个哈希函数族被称为 (d₁,d₂,p₁,p₂)-sensitive，需要满足？

答案：若 d(x,y) ≤ d₁ 则 Pr[h(x)=h(y)] ≥ p₁；若 d(x,y) ≥ d₂ 则 Pr[h(x)=h(y)] ≤ p₂（其中 d₁ < d₂、p₁ > p₂）。

即"近的更可能同桶、远的更不可能同桶"；两个概率差距越大，LSH 越好用。

Q11. 余弦距离 LSH 用随机超平面，两向量夹角 θ=60°（π/3），它们被哈希到同一桶的概率是？

答案：P = 1 − θ/π = 1 − 1/3 = 2/3 ≈ 0.667。

余弦距离 d = θ/π，所以 P = 1 − d，距离越近越容易同桶。

Q12. 数据 99% 是负类，模型把所有样本都判为负类。下列说法正确的是？

答案：Accuracy 高达 99%，但 Recall = 0、F1 = 0，模型毫无实用价值。

这就是"类别不平衡下 accuracy 会骗人"，应看 precision/recall/F1、PR 曲线或 ROC-AUC。

Q13. 降低分类阈值（更倾向判为正例），会怎样影响指标？

答案：Recall↑、Precision↓（FP 变多）。100% recall 很容易：把阈值降到最低，但那样 precision 极低。

Q14. k-means 每次运行结果可能不同，原因是？

答案：目标函数非凸、对初始质心敏感，不同初始化会收敛到不同局部最优。缓解：多次随机初始化取 SSE 最小、k-means++、先用层次聚类给初始中心。

Q15. BFR 算法中 DS（discard set）指的是？

答案：离某个簇质心足够近、可以被"丢弃"（只保留统计摘要）的点集；与它并列的还有 CS（compressed set，压缩集）和 RS（retained set，保留集）。

每个簇只需保存 (N, SUM, SUMSQ) 共 2d+1 个值，因此内存只与簇数有关。

Q16. SVD 中 A = U Σ Vᵀ，下列说法错误的是？

答案："V 的列是用户到概念的映射"是错的——U 的列（左奇异向量）才是 user-to-concept，V 的行（右奇异向量的转置）是 concept-to-movie。

Σ 对角线是奇异值，表示每个"概念"的强度，按降序排列。

Q17. 相比 SVD，CUR 分解的主要优势是？

答案：用真实的列和行（C 取自 A 的列、R 取自 A 的行）作为基，可解释，且能保持稀疏性。

代价是近似误差通常大于 SVD；SVD 在 Frobenius 范数下是最优低秩近似，但 U/V 是抽象的稠密向量。

Q18. 层次聚类用 single link（单链）的主要缺点是？

答案：Chaining（链式效应）：只要两个簇各有一个点较近就合并，容易把细长的簇连成一片，无法分开。

complete link（全链，最远点距离）倾向产生紧凑的球形簇；average link 取平均距离。

二、简答题（每题 6 分，共 36 分）

S1. 解释"相关不等于因果"，并给出相关关系的三种可能来源。

要点：①X 导致 Y；②Y 导致 X（方向相反）；③第三个变量 Z 同时影响 X 和 Y（confounder，如气温同时影响冰淇淋销量和溺水人数）；④纯巧合 spurious correlation（如"尼古拉斯·凯奇电影数"与"泳池溺亡数"）。

补充得分点：要确立因果需要对照实验/随机化，或因果推断方法，一般观测数据只能说明关联。

S2. 证明/解释：为什么 Min-Hash 满足 Pr[h(C₁)=h(C₂)] = Jaccard(C₁,C₂)？

要点：把行分成三类：a = 两列都为 1、b = 仅 C₁ 为 1、c = 仅 C₂ 为 1。

随机置换行后，从上往下扫，第一个"有 1 的行"必然落在 a ∪ b ∪ c 中，且均匀分布在这 a+b+c 行里，每种情况概率相等。只有当它落在 a 类（两列都为 1）时，两列的最小行号才相同。

所以 Pr[相同] = a/(a+b+c) = |C₁∩C₂| / |C₁∪C₂| = Jaccard。

S3. 说明 LSH 中 b（band 数）和 r（每 band 行数）分别如何影响 S-curve，以及怎么选？

要点：P = 1 − (1 − sʳ)ᵇ。

①r 控制曲线的陡峭程度：r 越大曲线越陡（从"几乎不可分"到"几乎全收"的过渡区越窄）。②b 控制曲线整体左右平移：b 越大越往左（阈值降低）。③阈值近似 s* ≈ (1/b)^(1/r)。

选法：先定住 b·r = 哈希函数总数，再按"希望在哪相似度处开始大量召回"来调；课件例子是 50 个哈希取 r=5、b=10。

S4. 为什么类别不平衡时 Accuracy 不可靠？应该看什么指标？

要点：Accuracy = (TP+TN)/N 把两类同等对待；当负类占 99% 时，全判负即可拿 99%，但正类 Recall = 0。

应看：Precision、Recall、F1、PR 曲线（不平衡时比 ROC 更能看出问题）、ROC-AUC；或做重采样/类别加权/调整阈值。

S5. 卷积神经网络相比全连接网络的两个核心设计是什么？各带来什么好处？

要点：①稀疏连接（局部感受野）：每个隐藏单元只连输入的一个局部 patch，符合图像的局部相关性，大幅减少参数。②权值共享（同一个 filter 滑过全图）：参数量与图像大小无关，并带来平移等变性/不变性。

配合 pooling 进一步降维、扩大感受野；深层堆叠使感受野逐层变大（高层看到更大范围）。

S6. 比较 SVD 与 CUR：各自原理、优缺点、适用场景。

要点：SVD：A = UΣVᵀ，取前 k 个奇异值得到最优 rank-k 近似（Frobenius 范数下误差最小）；缺点：U、V 稠密且是抽象线性组合，难解释、存储大。

CUR：A ≈ C·U·R，C 为采样到的真实列、R 为真实行、U 由行列交集 W 求得；优点：可解释（"为什么推荐这部"能追溯到真实用户/电影）、保持稀疏、计算/存储友好；缺点：误差一般更大（随机采样，按列/行范数平方的概率抽样以降低期望误差）。

场景：只要最优压缩/降维用 SVD；需要可解释、大规模稀疏矩阵用 CUR。

三、计算题（共 28 分）

C1（8 分）LSH 参数：b = 20、r = 5，求 s = 0.8 与 s = 0.3 时成为候选对的概率。

公式：P = 1 − (1 − sʳ)ᵇ，r = 5、b = 20。

s = 0.8：s⁵ = 0.32768 → 1 − 0.32768 = 0.67232 → 0.67232²⁰ ≈ 3.56×10⁻⁴ → P ≈ 0.9996（99.96%）

s = 0.3：s⁵ = 0.00243 → 0.99757²⁰ ≈ 0.9525 → P ≈ 0.0475（4.75%）

结论：这个参数组合的阈值大致落在 0.5–0.6 之间，相似度 0.8 的几乎全被找到，0.3 的基本被过滤掉——这正是 LSH 想要的"S 曲线"效果。

C2（6 分）Min-Hash 签名：全集 {r1..r5}，C₁={r1,r3,r5}，C₂={r3,r4,r5}；h₁: r1→2, r2→4, r3→1, r4→5, r5→3；h₂: r1→4, r2→2, r3→5, r4→1, r5→3。求两列签名与相似度估计，并比较真实 Jaccard。

h₁：C₁ 的值 {2,1,3} → min = 1；C₂ 的值 {1,5,3} → min = 1 → 相同。

h₂：C₁ 的值 {4,5,3} → min = 3；C₂ 的值 {5,1,3} → min = 1 → 不同。

签名：C₁ = (1,3)，C₂ = (1,1)；估计相似度 = 1/2 = 0.5。

真实 Jaccard：∩ = {r3,r5}（2 个），∪ = {r1,r3,r4,r5}（4 个）→ J = 2/4 = 0.5。

本题恰好相等；一般只有 2 个哈希函数时误差很大，哈希函数越多估计越接近真值。

C3（6 分）混淆矩阵：TP=30、FP=10、FN=20、TN=40。求 Accuracy、Precision、Recall、F₁、Specificity。

总数 N = 100。

Accuracy = (30+40)/100 = 0.70

Precision = 30/(30+10) = 0.75

Recall = 30/(30+20) = 0.60

F₁ = 2×0.75×0.60/(0.75+0.60) = 0.90/1.35 = 0.667

Specificity = 40/(40+10) = 0.80

C4（4 分）某矩阵奇异值为 σ = (10, 5, 2, 0)。求 ‖A‖_F、rank-2 近似的误差、rank-2 保留的"能量"比例。

‖A‖_F = √(10²+5²+2²+0²) = √129 ≈ 11.36

rank-2 误差 = √(σ₃²+σ₄²) = √(4+0) = 2（即 ‖A−A₂‖_F = 2）

保留能量 = (10²+5²)/129 = 125/129 ≈ 96.9%

要点：秩为 3（第 4 个奇异值为 0），所以 k=3 就是无损重建；误差公式是"被丢掉的奇异值平方和开根"。

C5（4 分）k-means 一轮迭代：一维点 {1,2,3,10,11,12}，k=2，初始质心 c₁=1、c₂=12。写出分配、更新后的质心与最终 SSE。

分配：1,2,3 距 c₁=1 更近 → 簇1 = {1,2,3}；10,11,12 距 c₂=12 更近 → 簇2 = {10,11,12}。

更新：μ₁ = (1+2+3)/3 = 2，μ₂ = (10+11+12)/3 = 11。

再分配：以 2、11 为质心，1,2,3 仍归簇1（3 距 2 为 1，距 11 为 8），10,11,12 仍归簇2 → 已收敛。

SSE：簇1：(1−2)²+(2−2)²+(3−2)² = 2；簇2：(10−11)²+0+(12−11)² = 2 → 总 SSE = 4。

注意：若初始化选成 c₁=1、c₂=3，则可能收敛到 {1,2,3} 与 {10,11,12} 之外的糟糕局部解——说明初始化很重要。

C6（4 分，SQL）给定 Students(sid, name, dept, gpa)、Courses(cid, dept)，写出"每个系中 GPA 高于 3.5 的学生人数，只保留人数≥2 的系，并按人数降序"。

参考：

SELECT dept, COUNT(*) AS cnt FROM Students WHERE gpa > 3.5 GROUP BY dept HAVING COUNT(*) >= 2 ORDER BY cnt DESC;

要点：WHERE 先过滤行（gpa > 3.5），GROUP BY 分组，HAVING 过滤组（人数），ORDER BY 排序。若学生可能 gpa 为 NULL，NULL 不满足 gpa > 3.5，会被自然排除。

⏱ 考前 30 分钟：只看这 6 条

  1. 相关≠因果的三种解释：X→Y、Y→X、共同原因 Z；观测数据不能直接证明因果。
  2. SQL：JOIN 语义 = 笛卡尔积后过滤；WHERE 过滤行、HAVING 过滤组；NULL 不参与 COUNT(列)/比较。
  3. LSH：P = 1 − (1 − sʳ)ᵇ。b↑ → 阈值↓（召回↑）；r↑ → 曲线更陡（阈值↑）。
  4. 指标：P = TP/(TP+FP)，R = TP/(TP+FN)，F₁ = 2PR/(P+R)；不平衡时 accuracy 会骗人。
  5. k-means：目标 SSE，两步循环（分配→更新质心），对初始化敏感；层次聚类不需要 k。
  6. SVD：A = UΣVᵀ；取前 k 个 = 最优低秩近似；误差 = √(σ²_{k+1}+…)，U 是概念、Σ 是强度、Vᵀ 是物品。

🚫 最容易丢分的 8 个细节

  • 算 LSH 概率时把 b 和 r 写反（b 是 band 数，在指数外层；r 是行数，在 s 的指数上）。
  • F₁ 用算术平均而不是调和平均。
  • precision 和 recall 的分子分母写反（P 的分母是"预测为正"，R 的分母是"实际为正"）。
  • SVD 里把 U 和 V 的"行/列"含义搞混。
  • k-means 更新质心时忘了除以簇内点数。
  • SQL 的 HAVING 写成 WHERE，或 GROUP BY 漏写非聚合列。
  • Min-Hash 签名是取"最小行号"，不是取最大值。
  • 比较 UNION（去重）与 UNION ALL（不去重）时说法含糊。
