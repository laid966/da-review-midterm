相似性搜索 II：距离度量、LSH 敏感族与 AND/OR 放大Similarity Search II高频

对应课件 p1–p65（抽取文本 PAGE 0–57）。本讲把 L3 的"Min-Hash + band"抽象成"任意距离度量都能做 LSH"：先记 4 条距离公理，再背 (d1,d2,p1,p2) 敏感族，最后会用 AND/OR 把族放大成阶跃曲线，并会算余弦（1−θ/π）与欧氏（a/2, 2a, ½, ⅓）两个具体族。

🎯 本节考什么

  • 会算：L1/L2/余弦/Jaccard 距离的具体数值；Pr[h(x)=h(y)] = 1 − θ/π（给夹角求概率、给概率反求夹角）；AND 放大 p → pʳ 与 OR 放大 p → 1−(1−p)ᵇ 的每一步数值；级联两次后的 p1、p2。
  • 会背：距离度量 4 条公理；(d1,d2,p1,p2)-sensitive 的两条不等式；Min-Hash 对 Jaccard 距离是 (d1,d2,1−d1,1−d2)-sensitive；余弦族是 (d1,d2,1−d1/π,1−d2/π)；欧氏族是 (a/2, 2a, 1/2, 1/3)；阈值 t 满足 1−(1−tʳ)ᵇ = t。
  • 会区分：相似度曲线（左低右高）vs 距离曲线（左高右低，翻转）；AND-OR：1−(1−sʳ)ᵇ vs OR-AND：(1−(1−s)ᵇ)ʳ；余弦距离 θ vs 余弦相似度 cos θ；d(x,x)=0 vs d(x,y)=0 ⇔ x=y。

核心概念 1：距离度量与四条公理

什么才算"距离"（p14）

d(·) 是距离度量，当且仅当它把任意两点映射成实数并满足四条：(1) 非负 d(x,y) ≥ 0；(2) 同一性 d(x,y) = 0 当且仅当 x = y；(3) 对称 d(x,y) = d(y,x)；(4) 三角不等式 d(x,y) ≤ d(x,z) + d(z,y)。三角不等式是最容易违反、也最常被考的一条。

课件口径差异（要留意）：L3 p10 写的是较弱版本 d(x,x) = 0（只保证"自己到自己为 0"），L4 p14 写的是更强的"当且仅当"。按 L4 的强版本记：第 2 条同时禁止"两个不同的点距离为 0"（否则叫伪度量 pseudometric，不能直接用标准 LSH 分析）。

Jaccard 距离：d(C1,C2) = 1 − |C1 ∩ C2| / |C1 ∪ C2| 余弦距离：d(A,B) = θ = arccos( A·B / (‖A‖·‖B‖) )，θ ∈ [0, π] L2（欧氏）：d(x,y) = √( ∑ᵢ (xᵢ − yᵢ)² )　　L1（曼哈顿）：d(x,y) = ∑ᵢ |xᵢ − yᵢ| 余弦距离可再除以 π 归一到 [0,1]。余弦相似度 cos θ = A·B/(‖A‖·‖B‖) ∈ [−1,1]，非负向量时 ∈ [0,1]（夹角不超过 90°）。注意 cos θ 本身不是距离：它越大越像、且相同向量得 1 而非 0。

怎么快速判定"这不是距离"

三步检查：先看 d(x,x) 是不是 0（余弦相似度在 x=x 时得 1，直接淘汰）；再看两个不同的点能否距离 0；最后试三角不等式，最常见反例就是"平方距离" d(x,y) = (x−y)²：在数轴上取 x = 0、y = 2、z = 1，d(0,2) = 4，而 d(0,1) + d(1,2) = 1 + 1 = 2，4 > 2，违反三角不等式。

数值例：x = (1,2,3)、y = (4,0,1) → L1 = 3 + 2 + 2 = 7；L2 = √(9 + 4 + 4) = √17 ≈ 4.12。这两个数考试常要求手算，注意 L1 是绝对值和、L2 是平方和再开方。

顺带复习：hash function 与 hash family 在这里的含义（p15）

"hash function"在这里被广义化成：任何能替你判断两个元素是否"相等"的函数，h(x) = h(y) 只是"h 认为它们相等"的简写。"family of hash functions"指一个能从中高效随机抽取一个函数的集合，典型例子就是所有行置换生成的 Min-Hash 函数族。LSH 的全部设计都发生在"族"这一层。

核心概念 2：(d1, d2, p1, p2)-sensitive 敏感族

若 d(x,y) ≤ d1，则 Pr_{h∈H}[ h(x) = h(y) ] ≥ p1 若 d(x,y) ≥ d2，则 Pr_{h∈H}[ h(x) = h(y) ] ≤ p2 前提：点空间 S、距离 d、函数族 H。d1 < d2 且 p1 > p2，否则族没有意义。概率是对"随机抽一个 h ∈ H"取的，不是对数据取的。

直觉与"曲线翻转"

近的点（距离 ≤ d1）被同哈希的概率至少 p1（高）；远的点（距离 ≥ d2）被同哈希的概率至多 p2（低）；中间地带 d1 < d < d2 定义不作要求。画成图时横轴是距离而不是相似度，所以曲线左高右低——课件 p17 原话是"注意这是距离不是相似度，因此 S 曲线是翻转的"。这是本讲最容易被写反的地方。

如果要把距离换成相似度画图，就得到 L3 那条左低右高的 S 曲线：相似度大 → 同桶概率大。两种画法等价的，但定义里的 p1 永远是配 d1。

把 L3 的 Min-Hash 翻译成这个语言（p18–p19）

设 S 为所有集合、d 为 Jaccard 距离、H 为所有行置换的 Min-Hash 函数族，则对任意 h ∈ H 有 Pr[h(x)=h(y)] = 1 − d(x,y)。于是 H 是 (d1, d2, 1−d1, 1−d2)-sensitive，对任意 d1 < d2 成立——因为 d1 < d2 ⇒ 1−d1 > 1−d2，正好满足 p1 > p2。

取 d1 = 1/3、d2 = 2/3，就得到课件 p25 那个必背的实例：Min-Hash 是 (1/3, 2/3, 2/3, 1/3)-sensitive。

这一节的意义：L3 只证明了"Jaccard + Min-Hash 能做 LSH"，L4 说明"任何距离只要找到敏感族就能照同样的套路做 LSH"。所以考题常问"LSH 为什么能推广到其它距离"——答：band 技术与具体度量无关，它只依赖 (d1,d2,p1,p2) 这个性质。

核心概念 3：AND / OR 构造与级联放大

AND 构造（对应一个 band 的 r 行）

从族 H 取 r 个函数组成 h = [h1, …, hr]，规定 h(x) = h(y) 当且仅当每个 hi 都相等。定理：若 H 是 (d1,d2,p1,p2)-sensitive，则 H′ 是 (d1, d2, p1ʳ, p2ʳ)-sensitive（用各 hi 独立，概率连乘）。效果：所有概率都被缩小——对大距离（p2）是好事（更接近 0），对小距离（p1）是坏事（也被压小）。

OR 构造（对应 b 个 band）

从 H 取 b 个函数，规定 h(x) = h(y) 当且仅当至少一个 hi 相等。定理：H′ 是 (d1, d2, 1−(1−p1)ᵇ, 1−(1−p2)ᵇ)-sensitive。效果：所有概率都被放大——对小距离（p1）是好事（更接近 1），对大距离（p2）是坏事。

所以标准做法是串联：先用 AND 把 p2 压到几乎 0，再用 OR 把 p1 抬到几乎 1，得到阶跃曲线。顺序反过来（先 OR 再 AND）也行，曲线是镜像，数值完全不同——见下面的对比表。

先 r 个 AND 再 b 个 OR（= L3 的 band 方案）：p → 1 − (1 − pʳ)ᵇ 先 b 个 OR 再 r 个 AND（镜像方案）：p → ( 1 − (1 − p)ᵇ )ʳ 前者就是 L3 的 1−(1−sʳ)ᵇ（把概率 p 换成相似度 s）；后者是它的水平+垂直镜像。阈值 t 定义在曲线上：对前者，t 满足 1−(1−tʳ)ᵇ = t。

完整数值例题：从 (.2, .8, .8, .2) 出发

设某个族把 d1 = 0.2、d2 = 0.8 映射成 p1 = 0.8、p2 = 0.2（近的点 80% 概率同哈希，远的 20%），这显然还不够用，要放大。

  1. 取 r = 4 做 AND-OR 方案的前半（也即 4-way AND 后 4-way OR，b = 4）：p1′ = 1 − (1 − 0.8⁴)⁴ = 1 − 0.5904⁴ = 1 − 0.1215 = 0.8785；p2′ = 1 − (1 − 0.2⁴)⁴ = 1 − 0.9984⁴ = 0.0064。得到 (.2, .8, .8785, .0064)。
  2. 取 b = 4 做 OR-AND 方案（先 4-way OR 再 4-way AND）：p1′ = (1 − 0.2⁴)⁴ = 0.9984⁴ = 0.9936；p2′ = (1 − 0.8⁴)⁴ = 0.5904⁴ = 0.1215。得到 (.2, .8, .9936, .1215)。
  3. 单次放大总有一头不完美：AND-OR 的 p2 极小但 p1 只有 0.88；OR-AND 的 p1 很高但 p2 高达 0.12。于是级联：把 (.2,.8,.9936,.1215) 再送进一次 (4,4) AND-OR，得 p1″ = 1 − (1 − 0.9936⁴)⁴ = 1 − 0.025357⁴ ≈ 0.9999996，p2″ = 1 − (1 − 0.1215⁴)⁴ ≈ 0.0008715。

结论：级联把"高概率"推到几乎 1、"低概率"压到几乎 0，代价是哈希函数数量按乘积增长——这一串 4×4×4×4 用了 256 个原始函数。课件 p43 的说法是：越接近 0 和 1，需要的哈希函数越多。

阈值 t 的含义与"何时算改进"

对曲线 p = 1−(1−sʳ)ᵇ 一定存在不动点 t，使 1−(1−tʳ)ᵇ = t。直观上 t 就是曲线的"台阶位置"：相似度高于 t 的点对被放大（概率抬高到 1 附近），低于 t 的被压低（概率压到 0 附近）。课件 p41 给出的判据是：只有当"低概率 < t 且高概率 > t"时，这次放大才是净收益；满足就可以一直迭代（计算量不是问题，函数数量才是）。

注意 p41 说的是"改进灵敏度"（improve the sensitivity），不是"任意参数都更好"。如果参数把一侧推过头（例如 r 太大导致 p1 也掉到 t 以下），放大就白做了。

独立性到底要求什么（p23）

上面所有"概率连乘"都用了各 hash 函数独立。真实的两个函数可能高度相关（例如两个 Min-Hash 置换在前一百万行上完全一样）。课件明确说：敏感族定义里的概率是对所有 h ∈ H 取的，是平均情形（average case）而不是最坏情形，所以个别相关的函数不破坏定义。答题时写"独立性用于乘积分解；定义只要求族上的平均性质"就够。

核心概念 4：余弦距离与随机超平面

哈希函数：随机超平面给一个 bit（p44）

随机取一个向量 v，定义 h_v(x) = +1 若 v·x ≥ 0，否则 −1，于是每个点被扔进两个桶之一。整个族 H = 所有向量 v 导出的函数。几何上：v 是超平面的法向量，v·x 的符号说明 x 落在超平面的哪一侧。

Pr[ h(x) = h(y) ] = 1 − θ / π，其中 θ = arccos( A·B / (‖A‖·‖B‖) ) 于是随机超平面族是 (d1, d2, 1 − d1/π, 1 − d2/π)-sensitive，对任意 d1、d2 成立（d 就是角度 θ）。这是必背的第二个具体族。

证明思路（考"为什么是 θ/π"）

只看 x 和 y 张成的那个平面（高维里两条向量必共面），问题降到二维。v 的方向在平面里均匀分布；v 与 −v 对应同一个超平面、同一个 bit 分法，所以只需分析半个圆周（角度范围 π）。当 v 的法向落在 x、y 的夹角 θ 之内时，它把两点分到超平面两侧，h(x) ≠ h(y)；落在夹角之外时同侧，h(x) = h(y)。所以 Pr[不同侧] = θ/π，Pr[相同] = 1 − θ/π。

课件 p47 特别提醒：判据是"超平面是否穿过这个角度"，别画成"向量 v 是否落在夹角里"——v 与 −v 是同一个超平面，画反了结论就错。

签名与工程细节

取 K 个随机向量，每个给 1 个 bit，就得到该点的签名（sketch）：一串 +1/−1。之后照 L3 的做法用 AND/OR 放大、分 band 打桶即可。数值感受：夹角 60° → Pr = 1 − 60/180 = 2/3；夹角 90°（正交）→ 1/2；夹角 30° → 1 − 30/180 = 5/6；完全同向 → 1。

效率问题（p54）：在高维 M 里生成一个真正随机的向量要 M 个随机数，太贵；实际只用每个分量取 ±1 的向量就够了，理由是数据随机时 ±1 向量在整个空间里分布均匀、不会引入偏向。这是个启发式假设，不是定理。

核心概念 5：欧氏距离与"投影到直线再分桶"

做法（p50）

随机选一条直线（方向 v），把这条直线切成宽度为 a 的桶；对每个点 x，先算它在直线上的投影（标量 x·v），再看这个投影落在哪个桶。哈希值 = 该桶的编号（一个整数）。直观：近的点投影也近，容易落同桶；远的点除非方向巧合否则落不同桶。

p51 画了三种情况：幸运（近点同桶、远点异桶）；不幸一（量化运气差：分界点正好卡在两点之间）；不幸二（投影运气差：v 几乎垂直于两点连线，投影挤在一起）。

若 d ≤ a/2，则同桶概率 ≥ 1 − d/a ≥ 1/2 若 d > 2a，则同桶概率 ≤ 1/3（要求 d·cos θ ≤ a ⇒ cos θ ≤ 1/2 ⇒ θ > 60°） ⇒ 对任意 a，该族是 (a/2, 2a, 1/2, 1/3)-sensitive 近点只在"分界点落在两点之间"时才分开，那个概率是 d/a，所以同桶概率 ≥ 1 − d/a。远点要同桶必须投影距离 d·cos θ 不超过桶宽 a；直线方向在 [0°, 90°] 上均匀，"θ > 60°"占 1/3。

为什么这条族"弱"，以及怎么补救

把 (a/2, 2a, 1/2, 1/3) 和 Min-Hash 的 (1/3, 2/3, 2/3, 1/3) 对比：这里 p1 只有 1/2、p2 是 1/3，本来就靠得近（比例 1.5）。做一次 r = 4 的 AND：(1/2)⁴ = 0.0625、(1/3)⁴ = 0.0123，比例虽然拉到 5 倍，但两个绝对概率都掉到很小；再用 OR 把 p1 抬回 0.9 以上（b = 36 时 1−(1−0.0625)³⁶ ≈ 0.90），p2 也会跟着涨到 1−(1−0.0123)³⁶ ≈ 0.36，根本没压住。也就是说，要达到与 Min-Hash 同样的阶跃，欧氏族需要多得多的函数——这正是 p43"越接近 0 和 1，需要的哈希函数越多"的量化体现。

推论（来自定义，不是课件原话）：族的 p1/p2 差距越小，达到同样的阶跃效果需要的函数越多、计算越贵。这也是为什么工程上高维欧氏检索常改用多表（multiple hash tables）或图索引（如 HNSW）来补救。

整条流水线（p39 / p57）：① 选距离度量 → ② 为该度量设计 (d1,d2,p1,p2) 敏感族（这一步"依赖距离函数"，是全讲唯一的创造性工作）→ ③ 用 AND/OR 级联把族放大成阶跃 S 曲线 → ④ 用 band 技术打桶，产出候选对 → ⑤ 在主内存里精确验证候选对，必要时再回原数据校验。

p57 的总结句值得抄：Pr[h(C1)=h(C2)] = sim(C1,C2) 这个性质是 LSH 的本质，没有它什么都做不了。LS 哈希函数负责把数据变成签名，band 技术（AND/OR）负责把签名变成阶跃的候选概率——两者缺一不可。

⚠ 易错点 / 命题陷阱

  • 曲线方向别写反。敏感族的横轴是距离：d1 处概率 ≥ p1（高），d2 处概率 ≤ p2（低），曲线左高右低。写成"d < d1 时概率 ≤ p1"等于把整讲写反。相似度版才左低右高。
  • d(x,x)=0 与 d(x,y)=0 ⇔ x=y 不是同一条。L3 p10 是弱版本，L4 p14 是强版本；作答 4 条公理时写"非负、同一性（当且仅当）、对称、三角不等式"，并指出第 2 条排除了"不同点距离为 0"。
  • AND 是 pʳ，OR 是 1−(1−p)ᵇ。AND 让所有概率变小（不是变大），所以必须再串 OR；两个公式不能互换，也不能把 OR 写成 1−pᵇ。
  • AND-OR ≠ OR-AND。1−(1−sʳ)ᵇ 与 (1−(1−s)ᵇ)ʳ 互为镜像，数值差很远：同一个 (.2,.8,.8,.2) 家族，AND-OR 给 0.0064，OR-AND 给 0.1215，差 19 倍。写公式前先确认"先 AND 还是先 OR"。
  • 余弦的概率是 1 − θ/π，不是 1 − θ/(2π)，也不是 1 − cos θ。θ 用弧度、π 对应 180°；正交（90°）时恰好 1/2，可用来快速自检。
  • 欧氏分桶只给下界。"d ≤ a/2 时同桶概率 ≥ 1 − d/a"是概率不等式，不是"一定同桶"；分界点可能正好卡在两点之间。
  • 独立性是"平均意义"的。定义里的概率对族取平均，两个具体函数可以相关；不要把"独立性"当成每个函数两两独立。

🧠 随堂自测

Q1 判定：下列哪些是距离度量？(a) L1；(b) 余弦相似度 cos θ；(c) Jaccard 距离；(d) 一维平方距离 (x−y)²；(e) 离散度量 d(x,y)=1（x≠y）、0（x=y）。

答案：(a) 是；(b) 不是——d(x,x) = 1 ≠ 0，违反同一性，方向也反（应为 1 − cos θ，真正做成度量还得用 θ = arccos）；(c) 是；(d) 不是——违反三角不等式，反例 x=0、y=2、z=1：d(0,2)=4 > d(0,1)+d(1,2)=2；(e) 是（离散度量，任意两点距离 1，三角不等式最坏情况 1 ≤ 1+1 成立）。

Q2 放大计算：族 (.2, .8, .8, .2)，先 r = 4 的 AND 再 b = 4 的 OR，求新 p1、p2；若先 OR 后 AND 呢？比较两者的用处。

答案：AND 先：(p1)⁴ = 0.4096、(p2)⁴ = 0.0016；再 OR：1 − (1 − 0.4096)⁴ = 1 − 0.5904⁴ = 0.8785，1 − (1 − 0.0016)⁴ = 0.0064 → (.8785, .0064)。

OR 先：(1 − 0.2⁴)⁴ = 0.9984⁴ = 0.9936，(1 − 0.8⁴)⁴ = 0.5904⁴ = 0.1215 → (.9936, .1215)。

比较：AND-OR 把"远的一定被排除"做到极致（p2 = 0.0064）但漏掉 12% 的近邻；OR-AND 几乎不漏近邻（p1 = 0.9936）但 12% 的远点会变成候选。两者互补，所以级联一次得到 (.9999996, .0008715)——代价是 4×4×4×4 = 256 个哈希函数。

Q3 余弦：两向量夹角 60°。(1) 一个随机超平面让它们同哈希的概率？(2) 10 个超平面的签名期望有几位相同？(3) 要用"至少一个相同就成候选"的方式以 ≥ 0.99 概率抓住它们，需要几个超平面？

答案：(1) Pr = 1 − θ/π = 1 − 60/180 = 2/3。(2) 每位独立的概率 2/3 → 期望 10 × 2/3 ≈ 6.67 位。

(3) 1 − (1 − 2/3)ᵇ ≥ 0.99 ⇒ (1/3)ᵇ ≤ 0.01。b = 4 时 (1/3)⁴ ≈ 0.0123 还差一点，b = 5 时 ≈ 0.00412 ≤ 0.01，故 b = 5。

Q4 欧氏：桶宽 a = 10。(1) 两点距离 d = 2 时同桶概率至少多少？(2) d = 25 时至多多少？(3) (a/2, 2a, 1/2, 1/3) 里四个参数各是什么含义？

答案：(1) d = 2 < a/2 = 5 → ≥ 1 − d/a = 1 − 0.2 = 0.8。(2) d = 25 > 2a = 20 → 要同桶需 cos θ ≤ a/d = 0.4，只占方向的约 1/3，故 ≤ 1/3。

(3) d1 = a/2 = 5 是"一定算近"的距离界；d2 = 2a = 20 是"一定算远"的界；p1 = 1/2 表示距离在 d1 以内时至少 1/2 概率同桶；p2 = 1/3 表示距离超出 d2 时至多 1/3 概率同桶。

记忆口诀：距离四查"非负、同零、对称、三角"；敏感族"近的高概率、远的低概率，曲线因横轴是距离而翻转"；AND 乘方压一切、OR 一减幂抬一切，串起来才成台阶，台阶位置 t 解 1−(1−tʳ)ᵇ = t；余弦"1 减 角度/π"，欧氏"宽 a 切片：(a/2, 2a, ½, ⅓)"。

P1

封面与本讲路线

这是 L4 的封面，主题是相似性搜索 II（Similarity Search II），幻灯片主要来自斯坦福 Jure Leskovec。它接在 L3 的三步流水线后面：L3 只把 Jaccard 加 Min-Hash 这一种情况讲透了，这一讲先把「距离度量」和「敏感族」抽象出来，再用 AND 与 OR 构造把任意敏感族放大成阶跃曲线，最后给出余弦距离（随机超平面）和欧氏距离（直线分桶）两套具体构造。带着这条主线看图：距离、敏感族、放大、分桶。

P2

回顾：为什么需要 LSH

考点

先把任务再说一遍：给定 N 达到百万甚至十亿（billions）级的文档集合，要找出所有近重复（near-duplicate）文档。难点在于两两比较的点对数是 N(N−1)/2，N = 10⁶ 时就有 5×10¹¹ 对，全比不可能。解法是本讲反复出现的套路：把文档哈希（hash）进桶，让相似文档以高概率落进同一个桶；同桶的那些对就是候选对（candidate pair），只对候选对再算精确相似度。所以 LSH 从头到尾都是「分桶筛候选加精确验证」两段式。

🎯 记住两段式：先筛候选，再算真相似度；LSH 本身不负责算相似度。

P3

三步流水线总图

考点

这页是整讲的骨架图，四个框从左到右：文档（Document）、文档中所有长度为 k 的字符串构成的集合、签名（signature，短的整数向量，用来代表集合并反映相似度）、局部敏感哈希（Locality-Sensitive Hashing）、候选对。看懂这张图的关键是每一步都在压缩：集合压成签名，签名再被分桶，最后只剩少数候选对；而压缩过程中相似度要尽量保持不变。第 4 到 12 页讲这条流水线，第 13 页之后开始推广到别的距离。

🎯 考过「写出三步及各自作用」，按压缩但不丢相似度来理解最稳。

P4

k-shingle（k-gram）定义

考点

第一段：把文档变成集合。k-shingle（也叫 k-gram）就是文档中长度为 k 的 token 序列，token 可以是字符也可以是单词。例子：k = 2、D1 = abcab，所有 2-shingle 是 ab、bc、ca；注意 ab 出现两次但集合里只算一个，5 个字符只得到 3 个元素。实践常用 k = 8、9、10，也可把 shingle 哈希成 4 字节整数省内存。好处是相似的文档会共享很多 shingle，而改一个词只影响附近 k−1 范围内（最多 k 个）shingle。

🎯 算 shingle 要去重：abcab 的 2-shingle 是 3 个而不是 4 个。

P5

Min-Hash：集合压成签名

考点

第二段：Min-Hashing。它把大集合换成短签名（signature），同时保持相似度，即 Pr[h(C1)=h(C2)] = sim(D1,D2)，也就是两篇文档签名相同的概率等于它们的 Jaccard 相似度。页面下方是签名矩阵（signature matrix）M 和两组数：列与列的真实相似度是 0.75、0.75、0、0，而签名之间的相似度是 0.67、1.00、0、0，大致对得上但不完全相等。因为签名只是估计量：期望等于真实相似度，单次会抖动，签名越长越准。

🎯 签名相似度只是估计：期望等于 Jaccard，不保证逐对相等。

P6

band 技术：签名矩阵分桶

考点

第三段：局部敏感哈希。把签名矩阵 M 按行切成 b 个 band、每个 band r 行（所以签名总长 M = b·r），每个 band 独立哈希到桶里。只要两列在至少一个 band 上完全相同，它们就是候选列对（candidate column pair）。图里左边是矩阵被横切成一条条 band，右边是若干桶，同一条 band 内完全相同的列被送进同一个桶。右下角提前给出坐标：横轴相似度、纵轴同桶概率，曲线在阈值 t 附近陡升。

🎯 M = b·r 是签名总长；b、r 是要调的参数，不是数据维度。

P7

推广思路：任意度量做 LSH

考点

这页从文档去重跳到一般点集。流水线换成：点（points）、签名、LSH、候选对，形状和 L3 完全一样。下面三句话点明通用套路：为给定距离（或相似度）设计一个局部敏感哈希函数；然后套用已有的 band 技术；最后记住换算关系 相似度 = 1 − 距离。也就是说换度量只改「哈希函数怎么设计」这一步，后面的分桶、放大、验证全都不变。下一页开始把这件事说得更精确。

🎯 换距离度量时，只有「设计敏感哈希函数」这一步要重做。

P8

S 曲线：LSH 的魔法

考点

这页给出本讲最重要的图形直觉。只用一个哈希函数（相当于 1 个 band、1 行）时，同桶概率就是 Pr[h(C1)=h(C2)] = sim，图上是一条 45 度直线：相似度 0.3 也有一半以上的机会同桶，太不挑。我们真正想要的是阶跃函数：低于阈值 t 几乎不可能同桶、高于 t 几乎一定同桶。课件的答案是靠选 r 和 b，把 band 内的 r 行做 AND、把 b 个 band 做 OR，这条直线就被掰成 S 形。

🎯 45 度直线是 r = b = 1 的特例；S 曲线是 AND 与 OR 放大后的形状。

P9

推导 1−(1−sʳ)ᵇ

考点

这页把 S 曲线算出来，必背。设两列相似度 sim = s：任意一行上两列签名相等的概率是 s；一个 band 的 r 行全部相等才算同桶，概率 sʳ；该 band 不相同的概率 1 − sʳ；b 个 band 都不同桶的概率 (1 − sʳ)ᵇ；所以至少一个 band 相同就是 1 − (1 − sʳ)ᵇ，这就是成为候选对的概率。推导只用一个假设：各行的相等事件相互独立，概率才能连乘。

🎯 写公式最容易漏括号：1−(1−sʳ)ᵇ，不是 1−(1−s)ᵇʳ。

P10

选 r、b 看曲线陡不陡

考点

曲线已经是 1−(1−sʳ)ᵇ 了，接下来是工程问题：r、b 怎么选。课件给的标准例子是总共 50 个哈希函数、取 r = 5、b = 10。图上横轴相似度、纵轴同桶概率，曲线在 0.6 到 0.7 附近陡升：相似度 0.3 的对只有约 2% 会成为候选，0.8 的对约 98% 会被抓到。课件一句话点题：不同的相似度阈值对应不同的权衡（tradeoff），想让曲线右移就更严格，想左移就更宽松。

🎯 记住标准配置：50 个哈希等于 r 5 乘 b 10，数值题常按它算。

P11

四种 r、b 组合的曲线

考点

这页用四张小图回答「调 r 和 b 各有什么效果」。左上 r = 1 到 10、b = 1：曲线族整体下压，说明 r 变大（band 更长）后同桶更难；左下 r = 1、b = 1 到 10：曲线族整体上抬，b 变多更容易同桶。右上 r = 5、b = 1 到 50 与右下 r = 10、b = 1 到 50：曲线都变成 S 形，但 r 越大越陡、位置越靠右。左边文字给结论：给定阈值 t，要选出让候选概率在 t 附近出现台阶的 r 和 b。

🎯 r 管陡不陡（精度），b 管台阶左右（召回）。

在线演示：Desmos 看曲线

这页不是新知识，而是一个可交互的 Desmos 演示（作者 Trenton Chang），截图里能拖动阈值、band 大小和行数来看曲线怎么变。复习时不用记链接，但要记住它能验证的两件事：一是 r、b 变大整体让曲线更陡；二是无论怎么调，曲线都还是 1−(1−sʳ)ᵇ 这个函数，且必过 (0,0) 和 (1,1) 两点。若被问「S 曲线为什么不是真阶梯」，答案就是：它是连续函数，b、r 越大才越逼近阶跃。

流水线插图复现

P14

能否推广到欧氏与余弦

转折页。前面用 LSH 找的是 Jaccard 相似度高的稀疏矩阵列，等价于集合相似。但现实里的相似常用别的度量：欧氏距离（Euclidean distance）、余弦距离（Cosine distance），例如图像特征向量之间的相似。于是本讲后半的任务是：把这些也纳入同一套框架，办法是先抽象出敏感族的定义，再用统一构造去放大，而不是为每种度量重编一套算法。

P15

距离度量的四条公理

考点

这页给距离下严格定义，四条缺一不可：非负 d(x,y) ≥ 0；同一性 d(x,y) = 0 当且仅当 x = y；对称 d(x,y) = d(y,x)；三角不等式 d(x,y) ≤ d(x,z) + d(z,y)。随后列出常用度量：Jaccard 距离等于 1 减 Jaccard 相似度；余弦距离是两向量夹角；欧氏 L2 是差平方和再开方；L1（曼哈顿距离 Manhattan）是差绝对值之和。注意「当且仅当」比「自己到自己为 0」更强，它禁止两个不同的点距离为 0。

🎯 平方距离 (x−y)² 不是距离：它违反三角不等式。

P16

哈希函数与哈希族

考点

为讲敏感族铺路。这里的哈希函数定义很宽：任何能替你判断两个元素是否相等的函数，h(x) = h(y) 只是「h 认为它们相等」的简写，它可以只给两个桶，也可以给很多桶。哈希族（family of hash functions）指一个能从中高效随机抽一个成员的集合，课件的例子是所有行置换生成的 Min-Hash 函数构成的族。有了族，才能谈「随机抽一个 h 时 h(x) = h(y) 的概率」。

🎯 敏感族里的概率是对随机抽取的 h 求平均，不是对数据求平均。

P17

敏感族定义：四元组

考点

本讲的核心定义。点空间 S 带距离 d，函数族 H 称为 (d1, d2, p1, p2)-sensitive，若对任意 x、y：距离小于 d1 时，随机取 h 属于 H 让 h(x) = h(y) 的概率至少 p1；距离大于 d2 时该概率至多 p2。直觉是近的点很可能同哈希、远的点很可能不同哈希，中间地带（d1 到 d2 之间）不作要求。课件最后一句是重点：只要找到这样一个敏感族就能做 LSH，band 技术与具体距离无关。

🎯 d1 配 p1（高概率）、d2 配 p2（低概率），写反即全错。

P18

敏感族曲线与 S 曲线镜像

考点

这页把定义画成图。横轴是距离 d(x,y)，不是相似度；纵轴是 Pr[h(x)=h(y)]。曲线左高右低：距离为 0 时概率接近 1，距离变大后掉下来；d1 处高度至少 p1，d2 处高度至多 p2。课件特意提醒：因为横轴是距离，这条 S 曲线和 L3 那条是镜像的。若把横轴换成相似度 s = 1 − d，就变回左低右高的经典 S 曲线，两种画法等价，但坐标轴不能混。

🎯 距离版左高右低、相似度版左低右高，先看横轴再画。

P19

把 Min-Hash 用距离重写

考点

把 L3 的定理翻译成距离语言。取 S 为所有集合、d 为 Jaccard 距离、H 为所有行置换的 Min-Hash 族，则对任意 h 属于 H 有 Pr[h(x)=h(y)] = 1 − d(x,y)。因为 L3 已证概率等于相似度，而相似度等于 1 − d，所以两句话是同一件事。这一步的意义在于：Min-Hash 现在也是一个族，可以套第 17 页的敏感族定义，于是 L3 的结论变成 L4 一般理论的一个特例。

🎯 概率等于 1 − d 是 Jaccard 专用；换成别的度量概率公式也就换了。

P20

实例：(1/3, 2/3, 2/3, 1/3)

考点

把上一页一般化：对 Jaccard 相似度，Min-Hashing 是 (d1, d2, 1−d1, 1−d2)-sensitive 族，对任意 d1 小于 d2 都成立，因为此时 1−d1 大于 1−d2，即 p1 大于 p2。取 d1 = 1/3、d2 = 2/3，就得到课件给的具体实例：Min-hash 是 (1/3, 2/3, 2/3, 1/3)-sensitive。读法：距离小于三分之一（即相似度至少三分之二）时，同哈希概率至少三分之二。这组四元组必背，常考由 d1、d2 推出另两个参数。

🎯 必背 (1/3, 2/3, 2/3, 1/3)，并会由 d1、d2 推出另两个参数。

P21

用 AND / OR 复现 S 曲线

提出问题：既然任何度量都能有敏感族，那 L3 那条漂亮的 S 曲线能不能照搬？答案是能，因为 band 技术只依赖概率，不依赖具体度量。两种构造：AND 构造相当于同一个 band 里的 r 行全相等，把概率乘起来；OR 构造相当于多个 band 至少一个命中，把概率合起来。图里画的就是把平缓曲线通过这两种操作掰成陡峭 S 形的过程。

P22

分节：放大哈希函数 AND/OR

过渡页，标题是放大哈希函数（Amplifying Hash Functions）：AND 和 OR。所谓放大（amplify）是把一个只做到「近的比远的更容易同哈希」的弱族，改造成「近的几乎必然同哈希、远的几乎必然不同」的强族。接下来 5 页依次讲：AND 构造的定义与定理、独立性假设的真实含义、OR 构造、两者对曲线的效果、以及如何把两者组合起来。

P23

AND 构造：概率变 pʳ

考点

AND 构造：从族 H 取 r 个函数组成 h = [h1, …, hr]，规定 h(x) = h(y) 当且仅当对所有 i 都有 hi(x) = hi(y)，等于一个 band 的 r 行全都相等。定理：H 是 (d1, d2, p1, p2)-sensitive 时，H′ 是 (d1, d2, p1ʳ, p2ʳ)-sensitive；证明只用各 hi 相互独立，概率直接连乘。图上两条注释是重点：它把大距离的概率压小（好事），同时把小距离的概率也压小了（坏事），所以单靠 AND 不够。

🎯 AND 要求全部相等，概率是 pʳ；它同时压低了好概率。

P24

独立性假设的真实含义

考点

为上一页的连乘补说明。独立性的实际含义是：两个哈希函数都说相等的概率，等于各自说相等的概率之积。现实中两个具体函数可能高度相关，例如两个 Min-Hash 置换在前一百万行上完全一样，那它们的结果就几乎绑定。课件的解释是：敏感族定义里的概率是对整个族取的平价值（average case），不是最坏情况，所以个别相关的函数不影响定义成立。

🎯 问「为什么能连乘」，答：定义取族上平均概率，再用独立性分解。

P25

OR 构造：概率变 1−(1−p)ᵇ

考点

OR 构造：取 b 个函数组成 h = [h1, …, hb]，只要至少一个 hi 认为相等，就说 h(x) = h(y)，等于 b 个 band 里至少一个命中。定理：H′ 是 (d1, d2, 1−(1−p1)ᵇ, 1−(1−p2)ᵇ)-sensitive。图上两条注释和 AND 相反：它把近点同哈希的概率抬高（好事），也把远点同哈希的概率抬高（坏事）。所以 AND 和 OR 单独用都不够，必须串起来。

🎯 OR 是至少一个相等，概率 1−(1−p)ᵇ，方向与 AND 相反。

P26

AND 与 OR 对曲线的效果

考点

这页是两张对照图，横轴都是一对 item 的相似度，纵轴都是同桶概率。左图 AND：r 从 1 到 10、b = 1，曲线族一层层往下压，箭头向下；文字说 AND 让所有概率收缩，但把 r 选对可以让低概率趋近 0、而高概率没被打下去太多。右图 OR：r = 1、b 从 1 到 10，曲线族往上抬，箭头向上；文字说 OR 让所有概率增大，b 选对可以让高概率趋近 1、而低概率没被抬太高。

🎯 AND 压全部、OR 抬全部；单独用都会坏，串起来才对。

P27

组合构造：先 AND 后 OR

考点

结论页：把 b、r 选对，能让低概率趋近 0 的同时高概率趋近 1。具体做法是 AND 构造后接 OR 构造（也可以反向，或任意交替），这正是 L3 里先按 r 行做 band、再让 b 个 band 取或的一般化。所以 L3 的 1−(1−sʳ)ᵇ 不是巧合，而是 r 路 AND 加 b 路 OR 这套构造在 Jaccard 距离下的具体形式。

🎯 两条路线：AND-OR 与 OR-AND，曲线互为镜像，顺序别写错。

P28

r 路 AND + b 路 OR = S 曲线

把两种构造接起来：先 r 路 AND（band 内 r 个值全同才同桶），再 b 路 OR（至少一个 band 同桶才算候选），得到的候选概率就是 1−(1−sʳ)ᵇ，也就是 L3 的 S 曲线。推导思路：设原始族里同哈希概率为 s，AND 后变 sʳ，OR 后变 1−(1−sʳ)ᵇ。课件给的例子是：先取 r = 4 做 AND，再从结果里取 b = 4 做 OR，接下来两页就是这组参数的表和曲线。

P31

假阴性 / 假阳性与阈值 t

考点

这页用 50 个哈希、r = 5、b = 10 的曲线定义两种误差。图上竖着画一条阈值 t（约 0.6）：蓝色区域 X 是假阴性率（false negative rate），即相似度大于 t 却没分享任何 band 的点对，它们永远不会成为候选，连算都没机会算；绿色区域 Y 是假阳性率（false positive rate），即相似度小于 t 却成了候选，代价只是多算一次精确相似度再丢掉，可以接受。调参时更该怕假阴性。

🎯 假阴性等于永远漏掉（严重）；假阳性等于白算一次（可接受）。

P32

固定 r·b = 50 的三种切法

考点

同样 50 个哈希函数，三种切法对比：r = 2、b = 25 时曲线最平缓，阈值靠左，能抓很多但假阳性多；r = 5、b = 10 居中；r = 10、b = 5 最陡，阈值最靠右，只抓很相似的，假阴性风险大。规律是：r 越大曲线越陡、阈值越高；b 越大阈值越低。于是选参数的思路是两步：先定想要的分辨率（陡不陡），再定想把它放在哪个相似度上。

🎯 固定 b·r 时：r 增大则阈值升、更严格；b 增大则阈值降、更宽松。

P33

反向构造：先 OR 后 AND

考点

换个顺序：先 b 路 OR、再 r 路 AND，候选概率变成 (1 − (1 − s)ᵇ)ʳ。课件说这是同一条 S 曲线在水平和垂直方向各镜像一次。用例子记：先取 b = 4 做 OR 得到 H′，再对 H′ 取 r = 4 做 AND 得到 H″。它和 1−(1−sʳ)ᵇ 数值完全不同：前者先抬再压、后者先压再抬，结果是近点更稳、远点更容易混进来。下一页是它的数值表。

🎯 两种顺序数值差很远，问哪个 p1 高、哪个 p2 低要能比。

P35

两次级联：概率推向两端

解决上两页各自的短板：把 (4,4) OR-AND 的结果再做一次 (4,4) AND-OR，(.2, .8, .8, .2) 就被变成 (.2, .8, 0.9999996, 0.0008715)，近点同哈希概率几乎 1，远点几乎 0。代价是哈希函数个数按乘积增长：4 乘 4 乘 4 乘 4 等于 256 个原始函数。这页要得出的一般结论是：级联把概率往 0 和 1 两端推，越接近两端需要的函数越多。

🎯 级联的代价是函数个数相乘（4×4×4×4 = 256），不是相加。

P36

阈值 t 与不动点方程

考点

定义阈值 t：对每条 AND-OR 曲线 1−(1−sʳ)ᵇ，都存在 t 满足 1−(1−tʳ)ᵇ = t，即曲线与 45 度直线的交点。它是分水岭：s 高于 t 的概率被抬高，低于 t 的被压低。判断一次放大是否划算的标准是低概率小于 t 且高概率大于 t，满足就可以继续迭代（计算量不是问题）。OR-AND 型曲线 (1−(1−s)ᵇ)ʳ 也有同样的不动点性质。

🎯 求 t 用 1−(1−tʳ)ᵇ = t，或直接近似 t 约等于 (1/b)^(1/r)。

P38

把任意距离对放大到极限

P42

分节：余弦距离的 LSH

分节过渡页：余弦距离的 LSH（LSH for Cosine Distance）。余弦距离衡量两个向量从原点出发的夹角，和向量长度无关，所以在文本、图像特征这类「方向比大小更重要」的检索里很常用。接下来 6 页讲它的构造：定义、随机超平面、概率公式 1 − θ/π、几何证明，以及用加减 1 向量省计算量的技巧。

P43

余弦距离与余弦相似度

考点

定义：余弦距离就是两向量从原点出发的夹角。d(A, B) = θ = arccos(A·B / (‖A‖·‖B‖))，取值 [0, π]，也就是 0 到 180 度；除以 π 就归一化到 [0, 1]。余弦相似度等于 1 减 d(A, B)，但更常见的定义是 cos θ = A·B/(‖A‖·‖B‖)：一般向量取值 −1 到 1，非负向量（夹角不超过 90 度）取值 0 到 1。注意 cos θ 越大越相似，而距离是角度本身，两者别混。

🎯 cos θ 是相似度不是距离；θ 除以 π 才是归一化到 [0,1] 的距离。

P44

随机超平面：敏感族参数

考点

给出结论：余弦距离用随机超平面（Random Hyperplanes）技术，做法和 Min-Hashing 类似，得到的族是 (d1, d2, 1 − d1/π, 1 − d2/π)-sensitive，对任意 d1、d2 都成立。对照下面复述的定义读：距离小于 d1 时同哈希概率至少 1 − d1/π，大于 d2 时至多 1 − d2/π，所以两个参数就是把距离除以 π 再取补。因为距离本身就是角度 θ，被 π 归一化，所以参数里出现 π 而不是别的常数。

🎯 必背 (d1, d2, 1−d1/π, 1−d2/π)，分母是 π 不是 2π。

P45

哈希函数 hv 与核心结论

考点

具体构造：每个向量 v 定义一个哈希函数 hv，只有两个桶：hv(x) = +1 当 v·x ≥ 0，否则 −1。整个族 H 就是所有向量 v 导出的函数的集合。几何上 v 是超平面的法向量，v·x 的符号告诉你 x 落在超平面哪一侧。结论是 Pr[h(x) = h(y)] = 1 − d(x,y)/π。直觉：夹角越小，越难找到能把两点分开的超平面，所以同侧概率越接近 1。

🎯 先记结论 Pr = 1 − θ/π；别记成 1 − cos θ。

P46

几何证明：超平面穿过夹角

考点

证明用的几何图。只看 x 和 y 张成的那个平面（两条向量必共面），问题降到二维。图中蓝色法向量 v 对应的超平面（蓝色虚线）落在夹角 θ 之外，所以 x、y 在同一侧，h(x) = h(y)；红色法向量 v′ 对应的超平面穿过夹角内部，把两点分到两侧，h(x) ≠ h(y)。课件右下角的提醒很关键：判据是超平面是否穿过这个夹角，而不是法向量本身落在哪里，因为 v 与 −v 是同一个超平面。

🎯 别把判据画反：看超平面（法向的垂线）是否穿过夹角 θ。

P47

得出 θ/π 的概率

考点

接着上一页收尾。法向量方向在平面里均匀分布，而 v 与 −v 等价，所以只需看半个圆周（角度跨度 π）。落在夹角 θ 内的比例是 θ/π，这些位置会把 x、y 分开（课件称 red case），于是分开概率等于 θ/π，同桶概率等于 1 − θ/π，也就是 1 − d(x,y)/π。两个特例可自检：夹角 0 时概率 1，夹角 180 度时概率 0。

🎯 自检点：正交（θ = 90 度）时同桶概率恰为 1/2。

P48

签名是加减 1 的 sketch

落地做法：随机取若干个向量，每个向量给每个数据点算一次 hv，得到一个 +1 或 −1 的比特；把这些比特拼起来就是该点的签名（也叫 sketch）。它和 Min-Hash 签名的作用完全一样：签名相同的位数比例就是余弦距离的估计，于是可以照搬 AND 与 OR 放大、以及 band 分桶。所以余弦 LSH 本质上是把 Min-Hash 换成随机超平面，其余部分原封不动。

P49

用加减 1 向量省计算量

考点

工程优化。维度 M 很大时，生成一个真正随机的 M 维向量要 M 个随机数，太贵。课件说只需考虑每个分量取 +1 或 −1 的向量就够了。理由是：假设数据本身是随机的，那么这种向量在整个空间里的方向也分布得足够均匀，不会引入系统偏差。注意这是启发式假设（原文是 assuming data is random），不是严格定理，答题时要带上这个前提。

🎯 加减 1 向量够用的前提是数据随机，不能当定理用。

P50

分节：欧氏距离的 LSH

分节过渡页：欧氏距离的 LSH（LSH for Euclidean Distance）。欧氏距离是直线距离，判断两点近不近要看实际间隔，而不是方向。构造思路和余弦不同：不是用超平面切空间，而是把点投影到随机直线上、再按固定宽度 a 分桶。接下来 6 页讲这套做法及其概率界，最后得到 (a/2, 2a, 1/2, 1/3) 敏感族。

P51

直线分桶：哈希即桶号

考点

欧氏 LSH 的核心想法：哈希函数对应一条直线。把这条直线按固定宽度 a 切成一个个桶，每个点先投影到直线上（算内积 x·v 得到标量），再看落在哪个桶，桶编号就是哈希值。签名里的每一位，就是某条投影直线给出的桶编号。直观：近的点投影也近，容易落进同一个桶；远的点除非方向巧合，否则会落在不同桶里。

🎯 近点不一定同桶（边界会切开），这里只有概率保证。

P52

幸运与两种不幸情形

考点

用图说明直线分桶为什么会出错。左侧是幸运情况（lucky case）：三个点投影下来，近的两个落进同一个桶，远的那个落在别的桶，完全符合期望。右侧两种不幸：上方是量化不幸（unlucky quantization），桶边界恰好卡在相近的点之间，把它们切开；下方是投影不幸（unlucky projection），投影方向几乎垂直于两点连线，本来相距较远的点投影后挤在一起、落进同一个桶。前者造成假阴性，后者造成假阳性。

🎯 术语对应：量化不幸则漏（假阴性），投影不幸则多（假阳性）。

P53

多投影：把桶号拼成签名

这页标题是 Multiple Projections（多重投影），回答「一条直线的一个桶号不够用怎么办」。图中两组点分别用两个不同方向的直线（都是宽度 a 的桶）投影，各得到一组桶号；最下面把两次投影的桶号排成一行，那就是签名。同样两组点在一条投影下可能恰好同桶、换一条投影就被分开，所以多条投影合起来能把偶然同桶的远点区分开，也为 AND 与 OR 放大提供了原料。

P54

近点同桶概率 ≥ 1−d/a

考点

量化近点同桶的概率下界。设两点距离 d、桶宽 a。它们投影到直线上相隔 d·cos θ；只有桶的边界恰好落在这段间隔里，两点才会被切开，而这个概率是间隔长度除以桶宽，即 d·cos θ 除以 a，它不超过 d/a，所以同桶概率至少 1 − d/a。图上画的就是随机直线、宽度 a 的桶，以及相距 d 的两点，并标出 d 远小于 a 时这个下界接近 1。

🎯 记牢 Pr(同桶) ≥ 1 − d/a，只在 d 远小于 a 时有用。

P55

远点同桶只能靠夹角巧合

考点

反过来看远点也能同桶需要什么条件。两点距离 d 远大于桶宽 a 时，投影间隔是 d·cos θ；要落进同一个桶，这个间隔必须小于一个桶宽，即 d·cos θ ≤ a，也就是 cos θ ≤ a/d。d 远大于 a 时右边接近 0，于是 θ 必须接近 90 度，即投影方向几乎垂直于两点连线，投影才会被压扁。图中画出了角度 θ 与投影长度 d·cos θ 的关系。

🎯 关键关系：投影间隔 = d·cos θ；同桶要求 d·cos θ ≤ a。

P56

得出 (a/2, 2a, ½, ⅓) 族

考点

把两个概率界代进敏感族定义。距离小于 a/2 时 1 − d/a 大于一半，所以同桶概率至少一半，取 d1 = a/2、p1 = 1/2。距离大于 2a 时要同桶，投影间隔 d·cos θ 必须不超过桶宽，即 cos θ 小于一半，也就是 θ 在 60 到 90 度之间；直线方向均匀，这段只占三分之一，所以取 d2 = 2a、p2 = 1/3。于是对任意 a 都得 (a/2, 2a, 1/2, 1/3)-sensitive 族，最后用 AND-OR 级联放大。

🎯 必背 (a/2, 2a, ½, ⅓)；θ 落 60 到 90 度只占 1/3 是关键一步。

P57

回头看完整设计流程

这页把全讲的流程图再画一遍，现在两栏都填满了：上面是 MinHash（文档到 0/1 矩阵再到整数签名），下面是随机超平面（数据点到加减 1 签名），两栏后面都接用 AND 与 OR 放大、以及 bands 技术，最后都产出候选对。它提醒你整讲的逻辑结构：不管哪种距离，都是设计敏感族、放大、分桶、验证四步，只有第一步的内容随度量而变。

P58

全讲总结：本质是那个等式

考点

总结页。课件把 LSH 的本质压成一句：哈希函数满足 Pr[h(C1)=h(C2)] = sim(C1,C2) 是「无它就什么都做不了」的性质；局部敏感哈希函数负责把数据变成签名，好让 band 技术（AND 与 OR 构造）接着用。复习时可以把整讲收成三步：先为某个距离找到满足这个等式的敏感族，再用 AND 与 OR 把族放大成阶跃曲线，最后分 band 打桶筛出候选对。

🎯 问「LSH 为什么能做近似最近邻」，答：靠这个等式加阶跃放大。
