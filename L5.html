核心概念 1：定义、三类学习、回归 vs 分类

两个定义（一起背，考选择/填空）

Arthur Samuel (1959)：机器学习是"让计算机在不被显式编程的前提下获得学习能力"的领域。关键词是 without being explicitly programmed——它给的是功能定义，强调"规则不是人写的"。

Tom Mitchell (1998)：程序从经验 E 中学习某类任务 T，并用性能度量 P 衡量；若它在 T 上的表现随 E 提高，就说它学会了。这是可操作定义，把"学习"拆成 T（任务）- E（经验/数据）- P（指标）三件套。

例：训练模型识别图像里的猫。T = 图像二分类（有猫/无猫）；E = 一批带标签的图像；P = accuracy。数据越多，P 越高，就"学到"了。

对照页 p4 的另一个例子：程序自己跟自己下棋。E = 下过的棋局，T = 下棋，P = 胜率。

学习成立 ⇔ P(T) 随 E 单调改善（Mitchell 1998） 答题时把三个字母换成具体任务/数据/指标，比背原句更容易得分。

三类学习（按有没有标签、有没有奖励分）

监督学习 supervised：数据带标签 (x, y)，目标是学 x→y 的映射，能预测没见过的样本。无监督 unsupervised：只有 x，没有 y，目标是找结构（聚类、降维，见 L6/L7）。强化学习 reinforcement：没有标准答案，只有环境返回的延迟奖励，智能体靠试错最大化累积回报（AlphaGo 自对弈）。

监督带标签 (x, y)学映射，预测新样本LR、KNN、SVM、决策树、随机森林、CNN

回归 vs 分类：看输出空间

回归 regression：y 是连续实数（房价、温度）。分类 classification：y 是离散类别（房子/联排、猫/狗），模型在特征空间里切出一圈决策边界 decision boundary，边界位置由参数决定。

分类可以只输出类别，也可以输出"给定 x 时各类的概率分布"，再取最大：这解释了后面"有些模型输出分数、必须选阈值"的说法。

回归：f: R^D → R^M，例 f(x) = wᵀx + b 线性回归就是拟合一条直线，最小化预测与真实值的误差。
分类：f: R^D → {1,…,K}，ŷ = argmax_k P(y=k|x) 输出概率时，取概率最大的类；边界就是"两个类概率相等"的地方。

核心概念 2：五个经典监督算法（会区分、会选）

Logistic Regression（LR，对数几率回归）

思路：对 x 做线性打分 w·x+b，再用 sigmoid 压到 (0,1) 当"属于正类的概率"，概率 ≥ 阈值（默认 0.5）判正，否则判负。决策边界是线性的：w·x+b=0。它不是"回归"任务，只是借用回归的打分再套一个概率函数。

课外补充：logit 形式 log(P/(1−P)) = w·x+b，这才是"对数几率"名字的来源；σ 的导数 σ' = σ(1−σ)，反向传播靠它；损失用交叉熵 −[y log ŷ + (1−y) log(1−ŷ)]。课件 p12–p15 是四页图片/视频（geeksforgeeks 图 + YouTube 链接），抽不到文字，公式按标准定义写。
P(y=1|x) = σ(w·x + b) = 1 / (1 + e^(−(w·x+b))) 输出概率 ⇒ 属"score-based"模型，必须选阈值；阈值不是模型参数。

KNN（k 近邻）

找离输入最近的 k 个训练样本，分类按多数投票、回归取均值。它"不训练参数、只存数据、预测时才算距离"，因此是非参数 non-parametric、基于实例 instance-based 的方法。k 小 → 边界跟着噪声走（过拟合）；k 大 → 边界太平滑（欠拟合，极端情况 k=N 时永远预测多数类）。

课外补充：距离度量（欧氏/曼哈顿/余弦）与特征标准化必须自己选，课件 p16 只说"找最近的 k 个"；量纲不同时欧氏距离会被大尺度特征主导，所以要先标准化。高维下距离趋于集中（维度灾难），KNN 会退化。

SVM（支持向量机）

在所有能把两类分开的超平面里，选间隔最大的那个。间隔 = 2/‖w‖，所以"最大化间隔"等价于"最小化 ‖w‖²"。只有落在间隔边界上的少数样本（支持向量 support vector）决定平面位置，删掉其它点不影响结果。

数据有噪声/线性不可分时加松弛变量 slack variable ξ，允许少量点越界，用 C 控制容忍度：C 大 → 少容忍 → 容易过拟合；C 小 → 间隔宽 → 更平滑。核技巧 kernel trick：把 x 映到高维空间，但只用核函数算内积，不显式做变换；常用 Linear、Polynomial、RBF 三类核。

课外补充：SVM 原始目标是"最小化 ½‖w‖² + CΣξᵢ"，约束是 yᵢ(w·xᵢ+b) ≥ 1−ξᵢ 且 ξᵢ ≥ 0。课件 p18–p23 全是图/视频，只给了"间隔、核、松弛"三个词，公式按标准形式补。
max 2/‖w‖ s.t. yᵢ(w·xᵢ + b) ≥ 1 硬间隔：所有点都在间隔外；2/‖w‖ 是两条边界线的距离。

决策树 DT 与随机森林 RF

决策树：根节点 = 整个数据集，内部节点 = 按某个特征做判断，分支 = 判断结果，叶节点 = 预测值。每次分裂都挑"让子集更纯"的特征。随机森林：训练很多棵树，每棵只看数据的不同随机部分（随机采样样本 + 随机挑特征子集），分类投票、回归平均，用"多棵树的平均"降低单棵树的方差、提高精度；代价是可解释性变差。

课外补充：树的分裂准则课件没给公式，考试若问，答"信息增益（ID3）/基尼指数（CART）越大越好"即可；树越深越容易过拟合，靠预剪枝（限制深度/叶子样本数）或后剪枝控制。RF 的随机性来自 bagging + 特征子采样，这两个词写上去基本能拿分。

核心概念 3：CNN 为什么有效（稀疏连接 + 权值共享）

先看全连接网络的两个毛病（p32）：① 每个输出单元与每个输入单元都相连，图像一大，参数量按“像素数 × 隐藏单元数”膨胀；② 相距很远的像素相关性很弱，全连接却给每个位置都配独立权重，既浪费参数，也把"平移后还是同一物体"这个先验丢掉了。

① 稀疏连接（local connectivity / receptive field）

隐单元只连输入的一小块局部区域，这块区域叫感受野 receptive field，对应的权值叫滤波器/卷积核 filter / kernel。灵感来自视觉皮层：一个神经元只对视野里某个小区域、某个朝向的亮线有反应。堆叠多层后，高层单元的感受野逐层变大，滤波器学到的模式从"边缘 → 纹理 → 部件 → 物体"越来越全局。

② 权值共享（shared weights）

同一个滤波器在整张图上滑动，不同位置的隐单元用同一组权值。原因：相似的边缘可能出现在任何位置，统计规律与位置无关。效果：参数量与图像尺寸脱钩，只由"核大小 × 核个数"决定（p37 的 100M → 100）。

100M→100 怎么来的：一个 1000×1000 的全连接层要 10⁶ 个权重；换成 100 个 10×10 的核，整层只有 100×100 = 10⁴ 个独立权重，因为这 100 个权重在 10⁴ 个位置上被反复复用。参数减少的是"独立参数个数"，不是乘法次数。

f(g(x)) = g(f(x))，g 为平移 参数共享让卷积层对平移"等变"（equivariance）：输入平移，输出跟着平移；再加池化才得到"不变"（invariance）。

核心概念 4：卷积层的算术（必考计算）

  1. 取输入特征图，尺寸 W_in × W_in × C_in。
  2. 每个滤波器是 F × F × C_in 的三维体，在输入上滑动，做"逐元素乘再加"。
  3. 在四周补 P 圈零（zero-padding），每次滑 S 个像素（stride）。
  4. 用 C_out 个滤波器各自得到一张输出图 → 输出 C_out 个通道。

隐节点在 (i,j) 的响应，就是把滤波器盖在输入对应的局部 patch 上做乘加；这一步等价于输入图 x 与学到的滤波器 w 做卷积，扫完整张图就得到一张特征图（filter map）。所谓“学到滤波器”，就是这组权重在训练中被反传调出来，因此它能表示某种局部模式（边缘、角点、纹理）。

W_out = floor((W_in − F + 2P) / S) + 1 floor 为向下取整；F 核宽、P 每边补零圈数、S 步长，高同理。不加 padding 时每层宽度减少 F−1，深层会迅速缩没，所以要补零或只用小核。
参数量 = (F × F × C_in + 1) × C_out "1" 是每个滤波器的偏置；C_out 是滤波器个数，也等于输出通道数（p52：32 个滤波器 → 32 通道）。

例：输入 32×32×3，8 个 5×5 核，P=2，S=1 → 输出 32×32×8，参数 (5×5×3+1)×8 = 608。同层改 S=2 → 输出 16×16×8，(32−5+4)/2 = 15.5 向下取整 15，再 +1 = 16。

多通道的细节（p50）：输入有 C_in 张特征图时，每个核是 F×F×C_in 的立方体，把各通道的卷积结果相加，才得到一张输出通道；所以"一个核 → 一张图"，"C_out 个核 → C_out 张图"。

核心概念 5：激活、归一化、池化、反向传播

激活函数

ReLU：max(0, z)，正区间梯度恒为 1，缓解梯度消失，输出稀疏；tanh：零均值、有饱和区，配 Xavier 初始化。（p57）

归一化：BN / LN / IN / GN 只看"在哪个维度上算均值方差"

y = γ · (x − μ) / √(σ² + ε) + β ε 防除零，γ、β 是可学习的缩放/平移；BN 还额外跟踪全局 μ、σ 供推理使用。

池化（pooling）：非线性降采样

Max pooling：把图切成不重叠（或重叠）的小块，每块取最大值；average pooling 取均值。输出图数不变、分辨率降低：上层计算量下降，并带来一定平移不变性。步长 s=1 时只做池化不降分辨率：仍能保留"特征有没有"的鲁棒性，但会丢"特征在哪"的信息——是否值得取决于任务（p67）。

反向传播在 CNN 里的三处不同（判断题高发）

① 卷积层敏感度（误差项）的算法与普通多层网络相同，但权值共享：一个 w 连着多个输入/输出位置，梯度必须把所有用到它的位置的贡献加起来。② 滤波器梯度 = 敏感度图与输入特征图的相关（p80），不是逐元素相乘。③ 池化层没有权重：max pooling 只把敏感度传给前向时取到最大值的那个位置（要记 argmax 索引），重叠窗口的敏感度要相加；average pooling 把敏感度平均分给窗口内所有位置。

典型结构（p72）：conv 增加特征图个数 → pooling 降低分辨率 → 每阶段可选 LCN/BN，末端接全连接 + softmax。AlexNet（p87）：5 个卷积层 + 2 个全连接层，max pooling 跟在第 1、2、5 个卷积层后；各层神经元数 290400 → 186624 → 64896 → 64896 → 43264 → 4096 → 4096 → 1000，共约 65 万神经元、6000 万参数、6.3 亿连接。

核心概念 6：训练的五个旋钮（knobs）

  1. 初始化：不能全零——同层神经元输出相同、梯度相同，等价于只有一个神经元（对称性问题）。常用小随机 N(0,0.01)；层数一深方差会逐层放大/缩小，所以要按扇入 n 缩放。
  2. 学习率：最需要调的参数。0.01 起步，监控训练/验证 loss，卡住就降 10 倍；NaN 崩溃多半是学习率太大。
  3. SGD 变体：Momentum（0.9，抑制震荡、加速一致方向）、Adagrad、Adam（lr=0.001，β₁=0.9、β₂=0.999）。
  4. mini-batch：用一小批样本估梯度，比单样本方差小、比全量便宜，还能喂满 GPU。
  5. BN + warm start：加 BN 可用更大学习率；继续训练时保存快照 resume（注意重新调学习率），或拿 ImageNet 预训练权重、只换最后一层做 fine-tune。
Xavier：w ~ N(0, σ²/n)；He：w ~ N(0, 2σ²/n) n 是扇入（该节点输入个数）。目的都是让每层激活方差与输入同量级，前向不炸不消、反向梯度同量级。

为什么 ReLU 要用两倍方差：Xavier 假设输入零均值、激活关于 0 对称；ReLU 把负半轴砍掉，平均只有一半单元是"活"的，等效扇入减半，所以方差补到 2σ²/n。

理论上的 η_t ≈ 1/(C+t) 只是凸优化的启发式，对非凸网络不保证；实践中"babysit"：等一等再降、用 SGD 迭代的滑动平均看 loss，不要每步在全量数据上算 loss。优化本身没有保证（非凸、可能慢），但通常能找到好的局部极小；过参数化（参数远多于样本）反而帮助优化，这一点课件自己标注"not well understood"。另三个常考小技巧：梯度检查（grad check，验证反传实现）、每个 epoch 打乱数据（data shuffling，避免 SGD 按固定顺序）、梯度裁剪（gradient clipping，防梯度爆炸）。

核心概念 7：评价指标（整讲最可能出计算题）

为什么要单独讲指标：训练用的 loss 只是真实目标的代理，不是所有错误代价相同（漏诊 vs 误诊）；指标把业务目标量化、用来估计与 baseline 的差距、诊断偏差/方差、衡量进展。

二分类模型两类：直接输出类别（KNN、决策树）和输出实数分数（SVM 的 margin、LR/NN 的概率）。分数模型要先定阈值才变成类别；对大多数指标而言只有排序重要。正例比例 prevalence = P/(P+N)。

以课件 p121 的数字为例（行 = 预测，列 = 真实标签，Th=0.5）
标签正标签负
预测正TP = 9FP = 2
预测负FN = 1TN = 8

矩阵性质（p121，判断题爱考）：总和固定 = 总体；列和固定 = 每个真实类的样本数；模型质量与阈值只决定"每列怎么拆到两行"；我们希望对角线"重"、非对角线"轻"。

Accuracy = (TP + TN) / (TP + FP + FN + TN) = 17/20 = 0.85 注意：课件 p127 抽取成 TP/(…)，是抽取时丢了 "+TN"；正确答案必须含 TN。
Precision = TP / (TP + FP) = 9/11 ≈ 0.818（课件 0.81） 分母是"预测为正"那一行。Precision 关心：报警的有多少是真的。
Recall = Sensitivity = TP / (TP + FN) = 9/10 = 0.9 分母是"真实为正"那一列。Recall 关心：真的有多少被找出来。
Specificity = TN / (TN + FP) = 8/10 = 0.8 负类的 recall，分母是真实为负那一列。课件写成 TN/TN+FP，漏了括号。
F1 = 2·P·R / (P + R) = 2TP / (2TP + FP + FN) = 18/21 ≈ 0.857 调和平均：P、R 有一个低，F1 就被拉低；不是 (P+R)/2。

换阈值会整体重排矩阵（p134）。阈值从 0.5 提到 0.6：TP 9→7、FN 1→3，而 FP=2、TN=8 没变（那两个负样本分数仍高于 0.6）。于是 Accuracy 0.85→0.75、Precision 0.81→0.78、Recall 0.9→0.7、F1 0.857→0.737（课件写 0.733，是中间结果提前四舍五入）。有效阈值个数 = 样本数 + 1：阈值从头扫到尾，就得到 ROC 与 PRC 两条曲线。

AUROC = ∫ROC = P(随机正例得分 > 随机负例得分) 横轴 1−Specificity（假正率），纵轴 Recall（真正率）。1 = 完美，0.5 = 随机猜；对 prevalence 不敏感。
AUPRC = ∫PRC，横轴 Recall、纵轴 Precision 阈值 = 0 时全判正，此时 Precision = prevalence，所以 PRC 不会低于 prevalence；AUPRC 可理解为"随机阈值下的期望 precision"，正例稀少时更敏感。

类别不平衡（prevalence < 5%，无严格定义）：全判多数类就能拿到 1 − prevalence（≥95%）的 accuracy，看起来很高；AUROC 也容易"靠把大多数负样本打很低分"维持在高位；AUPRC 相对稳健。课件的总结是：不平衡下三个指标的乐观程度依次是 Accuracy < AUROC < AUPRC，即 AUPRC 最"诚实"。

检测/分割另有指标：IoU = 预测区域与真实区域的交集/并集；mIoU = 先算每一类的 IoU 再取平均；pixel accuracy = 分类正确的像素比例。IoU 对"大物体里的小错"不敏感，mIoU 会惩罚小类别被忽略。

课外补充：IoU 公式课件 p132 只有标题，没给式子，但标准定义就是 Jaccard 系数 |A∩B|/|A∪B|——和 L3 的集合相似度是同一个公式，只是作用在像素/框上。

⚠ 易错点 / 命题陷阱

  • 混淆矩阵方向搞反：课件是"行 = 预测、列 = 标签"，TP 在左上、FN 左下、FP 右上、TN 右下。Precision 的分母是"预测为正"（TP+FP，行和），Recall 的分母是"真实为正"（TP+FN，列和）。四个格子填错，后面五个指标全错。
  • Accuracy 公式被"残缺版"带跑：p127 抽取文本是 TP/(TP+FP+FN+TN)，正确是 (TP+TN)/总。另外 prevalence=1% 时全判负就有 0.99 的 accuracy，所以不平衡下的 accuracy 基线是多数类占比（≈1−prevalence），别说"99% 说明模型很好"。
  • F1 当成算术平均：P=0.9、R=0.1 时 F1≈0.18 而不是 0.5；F1 只在 P、R 都高时才高。同理，提高阈值通常 Recall 下降、Specificity 上升，但 Precision 不一定单调变好。
  • 初始化与学习率混在一起：全零初始化的问题是"对称性"（同层神经元完全一样），不是"收敛慢"；随机初始化的目的是打破对称。tanh 配 Xavier（σ²/n），ReLU 配 He（2σ²/n），写反扣分。loss 出现 NaN 先怀疑学习率太大，而不是初始化。
  • CNN 的两个"数"分不清：参数量 = (F²·C_in+1)·C_out，与输入尺寸无关；连接数/乘法次数 ∝ 输出尺寸。权值共享减的是独立参数，稀疏连接减的是每层连接数，两者一起才让参数从"随图像尺寸增长"变成"只由核决定"。max pooling 反传只传 argmax 位置（重叠要累加），average pooling 才均分，池化层没有参数可更新。

🧠 随堂自测

Q1 计算：混淆矩阵 TP=9、FN=1、FP=2、TN=8。求 Accuracy、Precision、Recall、Specificity、F1；阈值提到 0.6 后变成 TP=7、FN=3、FP=2、TN=8，再算同样五个指标，并解释 Specificity 为什么没变。

答案：Th=0.5：总 20，Acc = (9+8)/20 = 0.85；Pr = 9/11 ≈ 0.818；Recall = 9/10 = 0.9；Spec = 8/10 = 0.8；F1 = 2×9/(2×9+2+1) = 18/21 ≈ 0.857。

Th=0.6：Acc = 15/20 = 0.75；Pr = 7/9 ≈ 0.778；Recall = 7/10 = 0.7；Spec = 8/10 = 0.8；F1 = 14/(14+2+3) = 14/19 ≈ 0.737。

Specificity 只统计"真实为负"那一列（TN+FP）。阈值升高只让 2 个原本判正的正样本跌破 0.6（TP→FN），负样本的得分仍然都在 0.6 以上，FP/TN 没动，所以 Spec 不变。这说明：单一指标不变不代表模型没变。

Q2 计算：输入 32×32×3，用 8 个 5×5 卷积核，padding=2、stride=1，输出尺寸与参数量？若 stride 改为 2 呢？

答案：输出边长 (32−5+2×2)/1+1 = 32，通道数 = 滤波器数 = 8，输出 32×32×8。参数量 = (5×5×3+1)×8 = 76×8 = 608（每个核 5×5×3 个权重 + 1 个偏置）。

stride=2：(32−5+4)/2 = 15.5，向下取整 15，+1 = 16，输出 16×16×8，参数量不变（还是 608）——这就是"参数与分辨率无关"的直接证据。

Q3 概念：AUROC 的概率含义是什么？prevalence=1% 时某模型 accuracy=99%，能说明它好吗？该看什么指标？

答案：AUROC = 随机抽一个正例和一个负例，正例得分高于负例的概率；也等于 ROC 曲线下面积，1 完美、0.5 随机猜。

不能。全判负就有 99% 的 accuracy，此时 Recall = 0，模型一个正例都没抓到。不平衡时应看 Recall/Precision/F1 或 AUPRC；AUPRC 的随机基线约等于 prevalence（0.01），而 AUROC 的随机基线恒为 0.5，所以 AUPRC 更能暴露"只会猜多数类"的模型。课件结论：不平衡下 Accuracy、AUROC、AUPRC 的乐观程度依次升高。

Q4 概念：为什么不能把权重全初始化为 0？Xavier 与 He 的方差为什么差 2 倍？

答案：全零时同层每个神经元的输入、输出、梯度完全相同，反向传播后更新量也相同，网络永远保持对称，等价于只有一个神经元，容量白费。

Xavier 假设激活零均值、关于 0 对称（tanh 近似满足），取 w ~ N(0, σ²/n) 让每层方差守恒；ReLU 把负半轴置零，平均只有一半单元激活，等效扇入减半，需要把方差补成 2σ²/n 才能维持同样的激活方差，这就是 He 初始化。

P4

Samuel 1959 定义

考点

第一个定义，也是常考原文。Arthur Samuel 1959：机器学习是让计算机具备在没有被显式编程的情况下学习的能力的研究领域。关键词是 without being explicitly programmed（无需显式编程）：传统程序靠人写规则 if…then…，机器学习则让机器从数据里自己找规则。注意这里的学习还是功能性说法，没回答「怎么衡量学得好」，下一页 Mitchell 补上这一点，两个定义要一起记。

🎯 常考填空：Samuel 1959 与 without being explicitly programmed。

P5

Mitchell 的 T-E-P

考点

接着给出可操作定义。Tom Mitchell 1998：若程序在任务 T 上的表现 P 随经验 E 提高，就说它从 E 中学到了东西。三个字母要会替换：识别猫时 T 是图像二分类、E 是带标签图片、P 是准确率；页面还给了自己跟自己下棋的例子，E 是下过的棋局、P 是胜率。考试常给一个场景让你填 T/E/P，答题要具体到任务类型、数据和指标，不能只写字母。

🎯 必背 T-E-P；答题要具体化，别只抄定义。

三类机器学习

考点

从定义转到分类。课件用一张最简单的三分图按任务划分：监督学习（有标签）、无监督学习（无标签）、强化学习（靠奖励）。这是全讲骨架，后面所有算法都能塞进这三个框。判断一个新方法属于哪类，只问两件事：训练时有没有标签 y、有没有环境给的奖励信号。图中三个框并列、没有箭头，表示它们是三种不同设定，而不是流程的三个阶段。

🎯 判类只看两点：有没有标签、有没有奖励。

P7

监督学习：学映射

展开三分图的第一个框。监督学习在带标签数据上训练，目标是学一个映射 f，使没见过的输入也能预测输出。关键词是泛化（generalization）：不是背下训练集，而是在新样本上表现好。这也是后面所有评价指标的动机——训练集准确率再高，不能泛化就没用。页面只有一句英文定义，抓住 labeled data、mapping、unseen data 三个词即可。

P8

房价预测：问题设定

考点

用具体例子解释回归。给定 n 个样本 (x₁,y₁)…(xₙ,yₙ)，x 是房屋面积、y 是价格；图中散点每个点是一个样本，第 15 个样本是 (x₁₅,y₁₅)。现在问面积 x=800 平方英尺的房子多少钱。800 对应的位置没有现成样本，所以不能查表，必须从已有样本中找出面积与价格的规律，这就是预测与查表的区别。

🎯 回归样本是 (x,y) 对，y 连续；别把预测当查表。

P9

房价预测：最小化误差

考点

这页补上怎么找规律：通过最小化预测价格与真实价格之间的误差，在面积和价格之间找到线性或非线性的关系。翻译成机器学习的语言就是：先假设一个模型（比如一条直线），用训练数据上的误差（损失函数）衡量它有多差，再调整参数让误差最小，这就是训练。后面讲的线性回归、梯度下降都围绕这句话展开，考试问训练流程就答这三步。

🎯 训练范式：定模型→定损失→最小化误差。

P10

回归 vs 分类

考点

给出区分标准：y 是连续实数（y∈R）就是回归，例如预测房价；y 是离散类别就是分类，例如同样给面积、地块大小，判断是独栋（house）还是联排（townhouse）。区别不在输入 x，而在输出 y 的取值集合：同一个 x 可以问价格（回归），也可以问房型（分类）。答题时先说 y 的类型，再举一个课件里的例子，比背定义得分高。

🎯 以输出 y 判断：连续→回归，离散→分类。

P11

回归的数学形式

把回归形式化：模型是从 D 维输入到 M 维输出的函数 f: R^D→R^M，最典型的是线性回归，用一条直线（高维时是超平面）拟合数据。图中散点配一条拟合直线，就是让误差最小的那条。页脚注明图来自 Bengio 等的《Deep Learning》。单变量回归时 M=1，多任务时 M>1；考试问线性回归的参数，答权重 w 和偏置 b，函数写作 f(x)=wᵀx+b。

P12

分类与决策边界

考点

分类模型写成 f: R^D→{1,…,K}，输出类别编号。f 由决策边界决定：边界把特征空间切成 K 块，落在哪块就判哪类，图上就是两类点被一条界线分开。另一种写法是输出概率分布 f(x)=P(y|x)，再取最大的类 ŷ=argmax_k P(y=k|x)。两种写法等价：两类概率相等的地方就是边界，所以后面逻辑回归也是先算概率再比大小。

🎯 argmax 取最大概率；概率相等处即决策边界。

P13

逻辑回归：输出概率

考点

进入逻辑回归（logistic regression）。这页回答「它是什么」：预测二分类（是/否、0/1）的概率；做法是先用线性组合把输入特征算成一个分数，再用 sigmoid 把分数压到 0 到 1，当作属于正类的概率，因此适合分类任务。图中流程是 Input Features→Linear Combination→S 形曲线，曲线右侧判为 Class 1、左侧判为 Class 0，分界大约在概率 0.5 处。

🎯 逻辑回归=线性打分+sigmoid，输出概率，不是类别。

P14

逻辑回归的三种类型

考点

承上页，按类别多少分三种。二项（binomial）：只有两类 0/1，例如是/否，就是标准逻辑回归；多项（multinomial）：多于两类且无序，例如猫/狗/羊，用 softmax 推广；有序（ordinal）：多于两类但有大小顺序，例如低/中/高。考试爱考多分类怎么办：无序多类用 softmax 回归，有序类别要按有序处理，不能直接套二项 logistic。

🎯 无序多类用 softmax；有序类别不能当无序。

P15

线性回归 vs 逻辑回归

考点

用对比图把两个容易混的名字分开。线性回归预测连续值、用最佳拟合直线、解决回归问题，曲线是一条斜线；逻辑回归预测类别、用 sigmoid 的 S 形曲线、解决分类问题，曲线两端饱和到 0 和 1。注意逻辑回归名字里有 regression，但它是分类器——只是借回归得到一个分数再转成概率。这是本节最常见的概念陷阱，选择题常拿它做错误选项。

🎯 逻辑回归是分类器，不是回归器（名字骗人）。

P17

KNN：k 个近邻

考点

换到 KNN（k-nearest neighbors）。它是监督算法，主要用于分类，也能做回归：对新输入，在训练集中找距离最近的 k 个点，分类按多数投票、回归取平均。课件强调两个性质：非参数（non-parametric，不假设数据分布、不学固定参数）和基于实例（instance-based，训练只是存数据，预测时才计算）。好处是直观、无需训练；代价是预测慢、怕高维。

🎯 KNN 非参数、懒惰学习；k 小过拟合，k 大欠拟合。

KNN 视频

SVM：分离超平面

考点

进入 SVM。这页给出两类点的散点图，中间一条粉色直线把蓝色圆点与红色叉号分开。关键观察：能把两类分开的线有无数条，这条只是其中一条，随便画也能在训练集上全对。那么该选哪条？这就是 SVM 要回答的问题：不是能不能分开，而是哪条最好、最稳。下一页会比较不同候选线，引出间隔的概念。

🎯 分类线不唯一，SVM 要选最稳的那条。

SVM：换一条线

承上页，把线换成一个角度更大的黄色实线，同样完全分开两类点，旁边多了一条粉色虚线。两页连起来说明：只要求把训练点分对，解是无穷多的，模型没有唯一答案。SVM 的思路是加一个偏好——让这条线离两类点都尽量远，这样对噪声最不敏感。虚线提示还存在与实线平行的另一条线，下一页会把它定义成间隔边界。

P21

SVM：边界不唯一

这页把绿色实线和黄色虚线一起画出来，两条线斜率不同，都能把两类点分开。到这里可以总结：线性分类器的假设空间很大，训练集分对只是最低要求。SVM 用最大间隔这个准则，从无穷多条线里挑出唯一一条——间隔越大，新样本稍有偏移也不容易跨过边界，泛化更稳。下一页给出间隔的严格定义和距离公式。

P22

SVM：间隔 margin

考点

定义间隔（margin）：离超平面最近的样本点到超平面的距离。图中超平面是绿线 w·x+w₀=0，两条虚线是平行边界，点到平面的距离写成 |w·x₁+w₀|/‖w‖。课件说大间隔更稳定：给数据加噪声后，点只要没越过间隔，分类结果就不变。注意决定间隔的是最近的样本，也就是后面的支持向量，其他点挪一挪并不影响这条边界。

🎯 间隔=最近点到超平面距离；大间隔抗噪。

P23

SVM 核技巧

考点

线性 SVM 处理不了一圈包一圈的数据（图中内圈蓝点、外圈橙点）。办法是核投影：把数据映射到更高维，在高维里就线性可分了；图上用高斯核把二维圆环抬到三维，再用一个平面切开。公式 f(x)=ΣαᵢyᵢK(xᵢ,x)+b 说明预测只依赖核函数算的内积；RBF 核写成 κ(x₁,x₂)=exp(−‖x₁−x₂‖²/2σ²)，σ 控制影响范围。

🎯 核技巧：只算内积不做显式映射；σ 控范围。

P24

SVM 松弛变量

考点

现实数据有离群点，硬间隔要求所有点都分对，会被一个噪声点带偏。这页引入松弛变量（slack variable）ξᵢ：约束从 y⁽ⁱ⁾w·x⁽ⁱ⁾≥1 放宽为 ≥1−ξᵢ 且 ξᵢ≥0，ξᵢ 度量该点越过间隔的程度。目标从 min‖w‖² 变成 min‖w‖²+Σξᵢ（课件省略了权重 C，标准写法是 CΣξᵢ）：C 越大越不容忍错分，越小间隔越宽。这叫软间隔。

🎯 ξ 量违约程度；C 大→硬、易过拟合，C 小→更平滑。

决策树：结构术语

考点

换到决策树（decision tree）。课件把它定义成图形化的决策表示：根节点（root）代表整个数据集；内部节点（internal node）按某个特征提问并分支；分支（branch）连接节点；叶节点（leaf）给出最终预测。图中从一个主问题开始不断二分，直到叶子。它天然可解释：从根到叶的一条路径就是一条 if-then 规则，这是它相对 SVM、KNN 的最大优势。

🎯 必背四个术语：根、内部节点、分支、叶。

决策树视频

P29

随机森林：多树投票

考点

承上页，单棵树容易过拟合且不稳定，随机森林（random forest）用很多棵树来改善：每棵树只看数据的不同随机部分（随机抽样本、随机抽特征子集），然后分类投票、回归取平均。效果是降低方差、提高准确率、减少单棵树随机性带来的波动；代价是可解释性下降。注意随机体现在两处：样本随机和特征随机，不只随机样本。

🎯 RF=bagging+特征随机；投票/平均降方差。

随机森林视频

P33

全连接网络的两个问题

考点

为什么不能直接用全连接网络处理图像？课件列两条：第一，每个输出单元与每个输入单元都相连，图像一大参数量就爆炸；第二，相距很远的像素相关性弱，全连接却给每个位置配独立权重，既浪费参数，又丢掉了平移后还是同一物体这个先验。这两条正好对应 CNN 的两个设计：局部连接与权值共享，下一页先讲第一个。

🎯 FC 两大毛病：参数爆炸、忽略空间局部性。

P34

稀疏连接与感受野

考点

CNN 的第一个设计叫稀疏连接（sparse connectivity）：隐单元只和输入的一小块局部区域相连，这块区域叫感受野（receptive field），连到它的权值就是滤波器/卷积核（filter/kernel）。课件说这受生物视觉系统启发：视觉皮层细胞只对视野中一小块区域的刺激有反应。图中每个 S 细胞只连前一层某个 C 平面的一小块，因此每层连接数大幅减少。

🎯 感受野=局部连接范围；滤波器=这组权值。

P35

视觉皮层实验

承上页，用神经科学证据支撑局部连接。实验在猫的视觉皮层插微电极，移动一根亮线，发现有些神经元只在亮线处于特定位置、特定朝向时才发放，有的还对运动方向敏感；大量这样的细胞平铺覆盖整个视野。这解释了为什么卷积核天然适合检测局部边缘与朝向。页面上还有 Fukushima 1980 的论文链接，是神经认知机的来源。

P36

稀疏连接是领域知识

这页是上一段的小结：稀疏连接来自领域知识（domain knowledge），我们知道图像有局部相关性，才这样设计，而不是让网络完全从零学。课件还留了一个开放问题：能不能把 CNN 用到频域（如傅里叶变换）？这属于延伸思考，不考。要记住的是：CNN 的归纳偏置来自图像的空间结构，这是它比全连接更省参数也更准的根本原因。

P37

感受野逐层变大

考点

单个卷积层只看局部，但把很多层叠起来，高层隐节点在输入图上的感受野会越来越大：浅层滤波器对应局部模式（边缘、角点），深层逐渐变成全局的部件甚至物体。图上画的就是从像素到边缘再到部件的层次变化。这解释了 CNN 的层次化表示：不是一层看全图，而是逐层把小模式组合成大模式，这也是深度学习可解释性讨论的起点。

🎯 层数越多感受野越大，特征越全局。

P38

权值共享与平移不变

考点

CNN 的第二个设计是权值共享（shared weights）：同一个滤波器在整张图上滑动，不同位置的隐单元用同一组权值。理由：相似的边缘可能出现在任何位置，统计规律与位置无关，参数不必随位置变化；这带来平移不变性（translation invariance），参数量也大幅减少（课件举例 100M→100）。注意有些应用只在局部共享，或顶层不共享。

🎯 权值共享=同一滤波器滑动复用，带来平移不变。

P39

卷积与等变性

考点

把上页的滑动写成运算：计算隐节点响应，等价于把输入图像 x 与学到的滤波器 w 做卷积，结果在隐藏层形成一张滤波图（filter map）。参数共享让这一层对平移等变（equivariance）：输入平移，输出特征图也跟着平移，而不是保持不变。注意等变与不变的区别：卷积是等变，池化才带来不变，这个区别常出判断题。

🎯 卷积是平移等变；池化才给不变性。

P40

卷积的定义

这页与上页内容几乎一致，仍强调：隐节点响应等于输入图与学到的滤波器做卷积，卷积后得到一张 filter map，权值共享使该层对平移等变。重复出现说明它是核心结论。把它写成可算的形式：输出某位置的值=滤波器与输入对应 patch 逐元素相乘再求和；等变性的数学写法是 f(g(x))=g(f(x))，g 代表平移操作。

卷积视频

P42

零填充：尺寸不缩

考点

卷积会让特征图变小：不加零填充时，每层宽度减少滤波器宽度减 1，层数一多表示就缩没了。所以实现上会在输入四周补零（zero-padding）把图撑大。图中对比了加与不加：输入四周多出来的一圈格子就是补出来的零，中间是原图。补零的另一个好处是能控制输出尺寸，甚至让输入输出同尺寸。

🎯 不加 padding 每层宽度减 F−1；补零可维持尺寸。

P43

补零让网络更深

考点

承上页，强调补零的作用：每层都补零，表示就不会随深度缩小，于是可以堆任意深的卷积网络。图来自 Bengio 等的《Deep Learning》，对比不同补零方式下尺寸的变化。注意 padding 不是免费的：边缘补零等于引入虚拟像素，输出图边缘的统计会受影响，所以 P 要合理，通常取 P=(F−1)/2、步长 1 时输出尺寸不变。

🎯 P=(F−1)/2、S=1 时输出与输入同尺寸。

P45

步长 stride

考点

为了省计算，可以不逐像素滑，而每 s 个像素取一次，这叫步长（stride），对应卷积写成 net[i,j]=(x∗w)[i×s, j×s]。直观上就是把输出图按比例缩小：s=2 时输出边长约减半。图中演示了不同步长下采样点的位置。代价是可能漏掉细节，所以 s 一般取 1 或 2，取太大等于强行降采样。

🎯 stride 直接缩放输出；s 越大越省、细节越少。

P46

stride 视频

考点

这页是 stride 视频，没有文字。视频演示滤波器按步长跳着走时输出图怎么变小。记住公式 W_out=floor((W_in−F+2P)/S)+1，步长在分母上。常见坑：除不尽要向下取整，例如 (32−5+4)/2=15.5，输出是 16 而不是 15.5 或 17。考试常直接给一组数字让你算输出尺寸，别忘记加 1。

🎯 除不尽向下取整；结尾的 +1 别丢。

P47

补零与步长四组合

考点

P55

Conv3D 体素识别

考点

从二维推广到三维。VoxNet 例子：输入是 (3.2m)³ 的点云，先转成 32×32×32 的占据网格（occupancy grid），用 32 个 5×5×5 滤波器、步长 2 得到 14×14×14×32，接着 32 个 3×3×3 滤波器加 2×2×2 最大池化得到 6×6×6×32，最后接 128 维全连接和 K 类输出（汽车）。3D 卷积多一个深度维，参数按核体积增长；输入换成视频时，深度维就是时间。

🎯 3D 核是 kD×kH×kW×C；池化三个方向一起降。

2D 卷积 vs 3D 卷积

非线性激活

考点

这页解释激活函数为什么必须有：如果没有非线性，无论叠多少层，矩阵乘法复合起来仍等价于一个线性变换，即 Output=W₃(W₂(W₁x+b₁)+b₂)+b₃=W'x+b'，多层网络会退化成一层。非线性激活打破这个限制，让网络能表示复杂的层次特征。图中画了 sigmoid 与 tanh 的 S 形曲线，以及 ReLU 在 0 处折一下的折线，正是这三种常用激活。

🎯 没有非线性，多层=一层线性变换。

P59

LCN 局部归一化

考点

LCN（local contrast normalization）在邻域内做归一化，可以沿空间维和特征维同时进行：把每个位置的值减去邻域均值、再除以邻域标准差，使局部对比度被拉平。好处是光照变化、整体明暗差异被抑制，网络更关注相对变化而不是绝对亮度。课件这页只给了一句定义加视频链接，理解到邻域内减均值除标准差即可。

🎯 LCN 在邻域内标准化：减均值、除标准差。

P60

为什么需要归一化

考点

这页用视频回答为什么需要 normalization：网络各层的输入分布会随参数更新而漂移（internal covariate shift），学习率只能设小、训练慢；逐层归一化把每层输入拉回稳定分布（均值 0、方差 1），于是可以用更大学习率、收敛更快、对初始化更不敏感。视频画面没有文字，记住这个动机即可，下一页开始讲具体方法 BN/LN/IN/GN。

🎯 归一化动机：稳定分布→大学习率、快收敛。

P61

BN 视频

这页是 Batch Normalization 的视频（YouTube 链接，画面黑屏），没有文字。BN 是对同一通道、跨一个 mini-batch 的样本做标准化：算这个 batch 在该通道上的均值与方差，把每个值标准化，最后用可学习的 γ、β 缩放平移。视频内容不用背，下一页用图讲清归一化方向，到时候对照看就懂了。

P62

BN 的归一化方向

考点

这页用竖条讲 BN 的方向：一根竖条是 1 个样本的 12 个特征，一个 batch 是 3 个样本并排；BN 沿同一通道、所有样本做统计，图中黄色框把三根竖条横向圈起来，标注 Normalization All sample with the same channel。记法：BN 竖着看单个样本、横着把样本合起来算。所以它依赖 batch 大小，batch 太小统计量会抖。

🎯 BN 统计维度：跨样本 (N,H,W)，同一通道。

P63

LN 的归一化方向

考点

对比 BN，这页讲 LN（layer normalization）：把往 z 轴方向（向纸面垂直）的一整条，即同一个样本的所有特征/通道放在一起做归一化。图中三根竖条并排成一个 batch，LN 在单根竖条内部算统计量，不跨样本。因此 LN 与 batch 大小无关，适合变长序列和 RNN。注意这里一个样本有 12 个特征、2 个通道。

🎯 LN 在单样本内统计：跨通道，不跨样本。

P64

IN 的归一化方向

考点

IN（instance normalization）：单样本、单通道各自独立做归一化，图中标注 One sample one time and channels are separated，即每个样本的每个通道单独算均值和方差。它比 LN 更细：LN 把所有通道合起来算，IN 把通道也拆开。风格迁移常用 IN，因为要抹掉每张图、每个通道的对比度差异，只保留内容结构，再换上目标风格。

🎯 IN 逐样本逐通道统计 (H,W)，风格迁移常用。

P65

GN 的归一化方向

考点

GN（group normalization）：把通道分成若干组，在单样本、每组通道内做归一化。课件定义：把通道分组、在每组内标准化，按样本独立，因此与 batch 大小无关。它介于 LN（所有通道一组）和 IN（每通道一组）之间，组数 G 是超参；图右下角的立方体标出 H、W、C、N 四个轴，蓝色切片就是一组通道。适合显存小、batch 开不大的任务。

🎯 GN=通道分组后组内统计；G 是超参，与 batch 无关。

P66

四种归一化对比

考点

这页把 BN、LN、IN、GN 画在同一张图里对比：立方体三个轴是 C（通道）、N（batch）、H/W（空间），蓝色格子是参与算均值方差的像素。BN 取 C 固定的切片（跨 N 和 H,W）；LN 取 N 固定的切片（跨 C 和 H,W）；IN 取 N、C 都固定的一小块；GN 取 N 固定、若干 C 的组。旁边给出公式：μ=(1/m)Σxᵢ，σ²=(1/m)Σ(xᵢ−μ)²，x̂=(x−μ)/√(σ²+ε)。记维度就是记这张图。

🎯 口诀：BN 跨样本、LN 跨通道、IN 单通道、GN 分组。

P67

池化：降采样

考点

池化（pooling）把输入图切成若干矩形区域，每个区域取最大值（max pooling）或平均值（average pooling），输出图数与输入相同但分辨率降低。作用是减少上层计算量，并提供一定平移不变性：特征只要在这个小区域内出现，池化后的值就一样大。课件称它为非线性降采样，并说明最大池化是把每个子区域的最大值输出，平均池化是备选方案。

🎯 池化：通道数不变、尺寸变小；max 给平移不变性。

P68

步长 1 的池化

考点

这页讨论一个细节：即使步长 s=1、不做降采样，池化仍然有用——它保留了特征是否存在的鲁棒性，同时丢掉了特征具体在哪的信息。课件说这取决于应用：只关心有没有（例如图里有没有猫）时池化合适；需要精确定位（检测、分割）时，过度池化会让位置信息丢失。图对比了有降采样与无降采样两种情况，并标注 invariance 与 information loss。

🎯 池化换不变性，代价是位置信息损失。

CNN 的扩展方向

P79

CNN 的反向传播

这页从「前向」转到「怎么训练」：CNN 同样用反向传播（back propagation）计算灵敏度（sensitivity），再据此更新卷积层与池化层的权重。课件点明关键区别：卷积层里灵敏度的计算与多层感知机（MLP）相同，真正的差别只在于卷积层有权值共享，所以求权重梯度时要把多个位置的贡献加起来——下一页就展开这个推导。

P80

卷积层求 ∂net/∂w

考点

这页解释为什么卷积层的梯度不能照搬全连接网络：普通网络里每个权重 W_ij 只连一个输入节点和一个输出节点，梯度很直接；而 CNN 因权值共享（weight sharing），同一个权重同时连到多个输入与输出位置。课件以 1 维为例：输入 x = [x₀, …, x_nx−1]，滤波器 w = [w_−d, …, w_d]，长度 2d+1；于是 ∂net/∂w 必须把该权重在所有滑动位置上的贡献累加。

🎯 权值共享是 CNN 参数少的原因，也是梯度要累加的原因。

P81

更新卷积核

承接上一页：卷积层滤波器的梯度可以写成灵敏度图（sensitivity map）与输入特征图的相关（correlation）。直观理解：哪个位置误差大（灵敏度大）、且那里的输入值也大，这个权重就该多改一点；把所有滑动位置的这种「误差 × 输入」累加起来，就是该滤波器的梯度，再按 w ← w − η·∂L/∂w 更新。

P82

池化层的灵敏度

池化层没有可学习权重，但梯度必须穿过它才能回到前面的卷积层。课件的设定是：第 l 层池化层的输入是上一层卷积输出的特征图 y^l，它的输出 x^(l+1) 又是下一层卷积的输入。最大池化（max pooling）的做法是：前向时记住每个窗口里最大值的位置（索引），反向时只把灵敏度传回那个位置，其余位置为 0；窗口不重叠时就是这样一一对应。

P83

重叠池化的梯度

考点

如果池化窗口是重叠的，一个输入节点可能同时是好几个输出窗口的最大值，于是反向传播时它会收到多份灵敏度。规则是把这些灵敏度相加，而不是只保留一份——因为前向时这个输入确实影响了多个输出。这是「重叠池化」与「不重叠池化」在实现上的关键差别，常作为判断题出现。

🎯 重叠池化反传要「相加」，不是取一次最大值。

P84

平均池化怎么反传

考点

换成平均池化（average pooling）时，反向传播把灵敏度平均分给窗口内每个位置（各得 1/k，k 为窗口大小）；若窗口重叠，同样把各次贡献相加。课件特别强调：池化层里没有需要更新的权重，反向传播在池化层只是把误差重新分配回输入，不更新参数。

🎯 池化层没有参数可更新，别答成「更新池化核」。

P85

AlexNet 与 ImageNet 突破

考点

这页是 CNN 的历史转折点：Krizhevsky、Sutskever、Hinton 在 NIPS 2012 用 CNN 做 ImageNet 物体识别，训练集是从网上收集的 100 万张图像、1000 个类别；用两块 GPU（每块 2GB 显存、系统内存 5GB）训练了整整一周。结果轰动：六个月后 Google 与百度用同样技术发布图像搜索，Google 称其视觉搜索准确率翻倍。

🎯 记数字：100 万张图、1000 类、两块 GPU、训练一周。

P86

ImageNet 数据集

考点

ImageNet 是这场突破的燃料：一个大规模图像分类数据集，规模就是上一页的数字（1000 类、百万级训练图像）。课件放这页是为了说明深度学习要靠大数据——同一套 CNN 在小数据集上很难赢过手工特征，在 ImageNet 这种量级上才显出优势。注意区分：ImageNet 是数据集，ILSVRC 是基于它举办的比赛。

🎯 数据集（ImageNet）vs 比赛（ILSVRC）别混。

P87

ImageNet 排行榜

这页是 paperswithcode 上 ImageNet 图像分类的 SOTA（state of the art）榜单截图。看榜时注意两点：横轴通常是时间、纵轴是准确率；2012 年 AlexNet 之后曲线出现明显抬升，说明深度模型在大规模视觉任务上第一次系统性超过传统方法。这也是「深度学习从哪一年开始碾压」这类问题的标准答案。

P88

AlexNet 结构：5 卷积 + 2 全连接

考点

AlexNet 的结构要能说清：5 个卷积层 + 2 个全连接层学特征；第 1、2、5 个卷积层后面跟最大池化。课件给了各层神经元数：290400、186624、64896、64896、43264、4096、4096、1000；总计约 65 万神经元、6000 万参数、6.3 亿连接。注意首层 290400 = 55×55×96，正体现「特征图变小、通道变多」；6000 万参数则主要来自后面几层全连接。

🎯 会问各层规模量级；首层 55×55×96 = 290400。

P89

AlexNet 的三个第一次

考点

课件总结了 AlexNet 的意义，三个「第一次」：第一次证明深度模型在大规模计算机视觉任务上有效；第一次采用超大规模深度模型；第一次显示 GPU 对这种大模型极其有效。答题时把「数据规模 + 深度模型 + GPU 算力」三件事一起写，就是深度学习起飞最完整的解释。

🎯 三个「第一次」：深度模型有效、规模空前、GPU 加速。

P90

硬件：GPU 与 TPU

这页把视角从算法转到硬件：训练 CNN 靠 GPU（图形处理器）加速矩阵运算，Google 又做了专用芯片 TPU。课件连问三个问题——一张卡能装多少张图像、TPU 与 V100 谁更快、类脑芯片是否可行——本质上都在追问「算力决定模型能多大」，这也是上一页第三个「第一次」的延伸。

P91

类脑芯片跑 CNN

一个具体例子：用忆阻器（memristor）做的类脑芯片跑 5 层 CNN 识别 MNIST。课件给的数字是 2048 个「一晶体管一忆阻器（1T1R）」单元组成阵列，准确率 96.19%。这页说明 CNN 的落地不只靠 GPU，也能在新型器件上实现；考题一般只问「这属于什么硬件、跑什么任务」。

P92

初始化：为什么不能全 0

考点

进入「训练神经网络的旋钮」系列（Knob 1 初始化）。神经网络的目标函数非凸（non-convex），所以初始化极其关键。第一个问题：能不能把权重全初始化为 0？不能。若全为 0，同一层每个神经元前向输出完全相同（对称性问题 symmetry problem），反向传播收到完全相同的梯度，它们永远学成同一种特征——网络退化成单个神经元，容量被浪费。

🎯 「权重全初始化为 0」是高频判断题：对称性→梯度相同。

P93

随机初始化与方差

正确做法是小随机数初始化：例如权重取自均值为 0 的高斯分布 N(0, 0.01)。接着课件提出一个推导题：某节点 v 有 n 个入边权重 w_i，若父节点输出也是零均值，节点 v 的激活 a[v] 的方差是多少？结论是方差约等于 n × 0.01 倍的输入方差——n 越大，激活值波动越大，深层网络就会出现梯度爆炸或消失，这正是下一页 Xavier 要解决的问题。

P94

初始化不当的后果

这页用图说明随机初始化尺度选错的后果：尺度太小，每层激活值的方差逐层缩小，信号与梯度一路衰减到接近 0（梯度消失）；尺度太大，逐层放大，激活饱和、梯度爆炸。图上通常一端是「太小」、另一端是「太大」，中间才是合适尺度——这就是 Xavier/He 初始化要「按 fan-in 缩放」的动机。

P95

Xavier 与 He 初始化

考点

解决办法：Xavier 初始化把标准差按入边数 n 缩放，让每个节点的方差归一化——若节点 v 有 n 个入边，权重取 N(0, σ²/n)。它假设父节点零均值且激活后仍零均值，但 ReLU 不满足（输出非负）。于是He 初始化针对 ReLU 修正：平均约一半单元被激活，所以把方差放大一倍，权重取 N(0, 2σ²/n)。

🎯 Xavier 用 σ²/n，He 用 2σ²/n；ReLU 配 He。

P96

Xavier 配 tanh，He 配 ReLU

考点

一句话总结前两页推导：Xavier 初始化在 tanh 激活下效果好，因为 tanh 零均值对称、符合 Xavier 的假设；它对 ReLU 效果不好，因为 ReLU 把负半轴截成 0、均值不为零，所以需要 He 初始化作为修正版。若问「ReLU 该用哪种初始化」答 He；问「谁假设零均值」答 Xavier。

🎯 配对题：tanh→Xavier，ReLU→He。

P97

学习率：最重要的旋钮

考点

Knob 2 是学习率/步长（step size，η_t），课件称它是「最需要调」的参数。凸优化理论给了一个 SGD 衰减策略：η_t ≈ 1/(C + t)，随迭代次数 t 逐渐变小；直观理解是越接近谷底步子越小。但课件马上提醒：这只是启发式（heuristic），对非凸的神经网络并不成立，实际要靠观察损失曲线来调。

🎯 「最重要的超参数」＝学习率，别答成 batch size。

P98

学习率大小的效果

这页用图展示学习率的三种典型表现：太小则损失下降极慢、像蜗牛爬；太大则损失来回震荡甚至发散（出现 NaN）；合适时损失快速而平稳地降到平台。记住这个「形状诊断法」：训练损失不降先怀疑 η 太小，震荡/爆炸先怀疑 η 太大——这是调参题的标准答法。

P99

调学习率的实操

考点

课件的实操建议：从一个合理值开始，η_t = 0.01；监控训练/验证损失；当学习停滞时把 η 降到原来的 1/10。三个 tips：① 别急着降，先等一会儿；② 想看训练损失时算全量数据太贵，可以用 SGD 迭代的滑动平均；③ 出现 NaN 之类崩溃，多半是 η 太大。

🎯 停滞降到 1/10；NaN 崩溃先怀疑学习率。

P100

SGD 及其变体

考点

Knob 3：SGD 与两个常用变体，课件直接给了 PyTorch 写法。普通 SGD：optim.SGD(model.parameters(), lr=0.01)，把模型参数交给优化器、lr 是每步的步幅；动量（momentum）：同一条语句加 momentum=0.9，用历史梯度平滑方向；自适应步长：Adagrad 用 lr=0.01，Adam 用 lr=0.001、betas=(0.9, 0.999)，会为每个参数单独调整步幅。课件特别强调 Adam 是最常用的自适应方法，不确定时先试它。

🎯 默认值：momentum=0.9、Adam lr=0.001、betas=(0.9,0.999)。

P101

动量为什么有用

SGD 的毛病：当损失曲面在某个方向很陡、另一个方向很平（曲率差异大）时，它会沿陡的方向反复震荡，前进很慢。动量正好修正这一点——对梯度方向经常变化的方向减小更新、对梯度方向一致的方向增大更新，从而抑制震荡、加速沿谷底前进。直观理解：像给小球加惯性，来回摆的被抵消、一直朝下的被累积。

P102

自适应步长示意图

这页是自适应步长（adaptive step sizes）方法的效果图，通常把 SGD、Momentum、Adagrad、Adam 在同一损失曲面上的轨迹画在一起对比：SGD 来回震荡、Momentum 顺谷底加速、自适应方法在陡与平的方向自动用不同步长。看图记住结论即可——自适应方法省去了大量手工调学习率的痛苦。

P103

Adam 是首选自适应方法

考点

课件点明：Adam 是最常用的自适应方法，写法 optim.Adam(params, lr=0.001, betas=(0.9, 0.999))。并给出实操建议：起步就二选一——(SGD + momentum) 或 Adam。也就是说不用把各种优化器都试一遍，先在这两个里选，再专心调学习率。课件还附了知乎与 CS231n 两个链接，说明这更像实践界共识而非理论结论。

🎯 二选一：SGD+momentum 或 Adam。

P104

Mini-batch：一次用一批

Knob 4：不拿单个样本估计梯度，而是一次用一小批（mini-batch）样本。好处是梯度估计的方差比单样本小、代价比全量低；同时矩阵运算能撑满 GPU 的并行度。batch 太大显存吃紧且泛化可能变差，太小则噪声大、训练慢——这就是 p109 把「设一个合适的 batch size」列为必调项的原因。

P105

批归一化

考点

Knob 5：批归一化（batch normalization）。做法是在每一层把该 mini-batch 内每个通道的激活标准化成零均值、单位方差，再学习缩放 γ 与平移 β。效果是缓解内部协变量偏移、允许用更大的学习率、降低对初始化的敏感度。这页主要是结构示意图，记住「按 batch 统计、发生在激活函数之前」即可。

🎯 BN 的两个可学参数：缩放 γ、平移 β。

P106

热启动与预训练

附加旋钮：热启动（warm start）/预训练（pre-training）。两种用法：① 想接着训练更多轮（epoch）时，保存权重快照后从中恢复，但要小心重新设置学习率；② 拿别的任务训好的权重当新任务的初始化做微调（fine-tuning），例如用 ImageNet 图像分类网络的特征，只替换最后一层来适配新任务。

P107

热启动的学习率注意

与上一页内容相同，但课件额外强调一句：恢复训练时要特别小心步长/学习率。原因很直白：原来的学习率是为「刚开始、权重还很差」的状态调的，此时权重已经训练得不错，用同样大的步长会把已学到的结构破坏掉，所以通常要从更小的学习率重新开始并盯住验证损失。

P108

神经网络优化的现实

小结神经网络的优化：主技术是随机梯度下降（SGD），反向传播（back propagation）负责高效算梯度；理论上没有任何保证——目标非凸、可能训练很久，但实践中往往能找到不错的局部极小。课件还提到一个反直觉现象：过参数化（over-parameterization），网络大到参数比样本还多时优化反而更容易，课件坦言这一点「尚不清楚」。

P109

优化技巧清单

考点

本讲最像考点清单的一页，逐条背：① 梯度检查（gradCheck）确认反向传播写对；② 数据打乱（data shuffling）给 SGD 随机样本顺序；③ 梯度裁剪（gradient clipping）避免梯度爆炸；④ 初始化用 He/Xavier 或 warm start；⑤ 学习率靠训练/验证损失调；⑥ SGD 变体：Momentum（默认 0.9）或 Adam（β₂=0.999 ≫ β₁=0.9）；⑦ mini-batch 选合适 batch size；⑧ 用 batch normalization。其中梯度裁剪针对的是梯度爆炸，而初始化与 BN 都是为了让各层数值尺度保持稳定。

🎯 八条按「检查→顺序→裁剪→初始化→学习率→优化器→批大小→BN」记。

P110

优化技巧（视频）

这页只有标题和一个视频链接，属于拓展，没有新公式。真正的考点都在上一页的清单里：梯度检查、打乱数据、梯度裁剪、初始化、学习率、优化器变体、mini-batch、批归一化这八项。看视频之前先把那八条背下来，性价比更高。

P111

CV 任务一：图像分类

从这页起进入「计算机视觉里的监督学习」四个任务。第一个是图像分类（image classification）：输入 x = 图像的原始像素（raw pixels），输出 y = 图中的主要物体类别。数据集是 ImageNet 大规模视觉识别挑战赛（ILSVRC）。这正是 p85–p89 的 AlexNet 所解决的任务，也是后面三个任务的基准。

P112

分类结果示例

分类结果的可视化：输入一张图，模型给出它认为最可能的若干类别及对应分数。看图时注意两点：① 正确类别是否排在第一、分数是否明显领先；② 相似类别（比如不同犬种、不同车型）常常挤在一起，说明模型学到的是细粒度差别——这也是分类任务在细类上更难的原因。

P113

CV 任务二：定位与检测

考点

第二个任务是目标定位与检测（localization and detection）：输入同样是原始像素，但输出 y = 边界框（bounding boxes）。课件把两者分得很清楚：定位（localization）只预测单个物体周围的框坐标；检测（detection）要找出图中多个物体，并给每个物体一个类别标签和一个边界框。

🎯 定位＝单物体一个框；检测＝多物体各自类别+框。

P114

检测结果示例

检测结果的可视化：一张图里画出多个边界框，每个框旁边标类别与分数。看图时注意区分「漏检」与「误检」——漏掉真实物体对应后面的 FN（false negative），框错位置或标错类对应 FP（false positive）。这两类错误在 p122–p127 的混淆矩阵里会用 TP/TN/FP/FN 精确计数。

P115

CV 任务三：语义分割

考点

第三个任务是语义分割（semantic segmentation）：输入仍是原始像素，但输出 y = 每个像素的类别标签——不再是框，而是逐像素分类，所以输出是一张与原图等大的类别图。它比检测更细：检测只说「这里有一只猫」，分割要说「这一片像素属于猫」。正因如此，它的评价指标要用 IoU/mIoU（p133–p134）。

🎯 三个任务的 y 不同：类别 / 框 / 逐像素标签。

P116

分割结果示例

分割结果的可视化：左原图、右预测，不同颜色代表不同类别（道路、建筑、天空……）。看这类图要关注边界是否贴合、小物体是否被漏掉。这页引用的是 Chen 等 ECCV 2018 的编码器–解码器加空洞可分离卷积工作（DeepLab 系列），也就是先把特征图降分辨率、再上采样回原尺寸的典型做法。

P117

大纲：ML 基础与评估

考点

课件在这里换章节：接下来讲机器学习基础，分两块——① 机器学习的定义与类型（definitions and types of ML）；② 机器学习评估（evaluation of machine learning）。后半讲（p118 起）全部是评估：为什么要指标、二分类的分数模型、混淆矩阵、各种点指标、ROC/PRC 曲线、类别不平衡——这是考试的绝对重点。

🎯 p118–p140 是评估专题，属于必考区。

P118

为什么需要评估指标

课件给了六条理由：① 训练目标（代价函数）只是真实目标的代理（proxy）；② 指标能把业务目标量化，因为不是所有错误都等价（漏诊与误诊代价不同）；③ 指标让团队努力方向一致；④ 通常体现为在验证集（dev set）上提升某指标；⑤ 能量化「期望表现与基线」「期望与当前」的差距、衡量进步；⑥ 便于诊断偏差与方差。理想情况训练目标就该是指标，但计算或数学上常做不到。

P119

二分类：两类模型

考点

二分类设定：x 是输入，y 是 0/1，模型 ŷ = h(x)。课件把模型分两类：① 直接输出类别的（K-近邻、决策树）；② 输出实数值分数的（SVM 输出间隔 margin、逻辑回归/神经网络输出概率），此时必须选一个阈值（threshold）把分数变成最终类别。本讲后续聚焦第二类，因为第一类可以看作它的特例。

🎯 SVM 的分数是 margin，逻辑回归/神经网络是概率。

P120

分数模型与患病率

考点

分数模型的直观图：正样本与负样本按分数 0 到 1 排开，两类分布有重叠。对大多数指标而言只有排序（ranking）重要，绝对分数值本身不重要。样本太多不方便逐个看时，就画按类别的分数直方图。这页还定义了患病率/正例占比（prevalence）= 正例数 ÷（正例数 + 负例数），它在 p139 的类别不平衡里会反复出现。

🎯 prevalence 公式必背，后面不平衡分析全靠它。

P121

阈值把分数变分类器

考点

这页建立后面所有点指标的几何图像：用阈值 Th=0.5 把分数轴切成两段，高于阈值判为正（predict positive）、低于判为负（predict negative）；再与真实标签（label positive/negative）交叉，就得到四个格子。可以把它想成一个 2×2 表格：行是预测、列是真实，四个格子分别对应 TP、FP、FN、TN。

🎯 记住行列方向：行＝预测，列＝真实，别转置。

P122

混淆矩阵

考点

这页给出具体混淆矩阵：TP=9、FP=2、FN=1、TN=8，合计 20 个样本。课件列了四条性质：① 总和固定（等于总体样本数）；② 列和固定（每类的真实数量固定，这里正例 10、负例 10）；③ 模型质量与阈值决定「每一列怎么拆成两行」；④ 我们希望对角线重、非对角线轻。用它算准确率：(9+8)/20 = 0.85。

🎯 9/8/2/1 这组数后面所有指标都靠它算，务必记牢。

P123

TP：真阳性

逐个定义四个格子。TP（true positive）= 真实为正、预测也为正 = 9。它出现在「预测正」行与「标签正」列交叉处，是模型抓对的正例。注意 TP 同时出现在准确率、精确率、召回率、F1 的分子里——它是所有指标的核心，剩下的 FP、FN、TN 都在回答「另外那些样本去哪了」。

P124

TN：真阴性

考点

TN（true negative）= 真实为负、预测也为负 = 8。它是模型正确排除的负例。TN 只出现在准确率（accuracy）与特异度（specificity）的分子里——这是它与 TP 的关键区别：正类的指标不看 TN，负类的指标才看。特异度的公式是 TN/(TN+FP)，分子正是 TN。TN 越大、特异度越高，说明模型越少冤枉负类。

🎯 问「哪个指标用到 TN」：accuracy 与 specificity。

P125

FP：假阳性

考点

FP（false positive）= 真实为负、却被预测为正 = 2，俗称「误报」：把没有的说成有（垃圾邮件误判、健康人被判有病）。它在「预测正」行、非对角线位置，会让精确率（precision）下降，因为精确率的分母 TP+FP 里多了它。顺带记住：FP = Type-1 error（第一类错误）。误报的代价决定阈值往哪边调：宁可漏报时就抬高阈值，FP 会随之减少。

🎯 FP 是「冤枉好人」，故精确率掉；FP=Type-1。

P126

FN：假阴性

考点

FN（false negative）= 真实为正、却被预测为负 = 1，俗称「漏报」：把有的说成没有（病人被判健康、垃圾邮件进了收件箱）。它会让召回率/敏感度（recall/sensitivity）下降，因为召回率的分母 TP+FN 里多了它。记住：FN = Type-2 error（第二类错误）。FP 与 FN 的代价通常不同，这正是 p118 说的「不是所有错误都等价」。

🎯 FN 是「放过坏人」，故召回率掉；FN=Type-2。

P127

两类错误的别名

考点

这页只讲一件事：FP 与 FN 在统计学里另有两个名字——FP 叫第一类错误（Type-1 error），FN 叫第二类错误（Type-2 error）。记忆方法：Type-1 是「冤枉好人」（把负判成正），Type-2 是「放过坏人」（把正判成负）。课件在这页注明图片的原始出处没找到，但不影响考点，四个格子的定义才是要记的。

🎯 考题写「Type I error」指的是 FP，不是 FN。

P128

Accuracy 准确率

考点

点指标之一：Accuracy =（TP+TN）/（TP+FP+FN+TN），即 (9+8)/20 = 0.85。注意这页课件公式的抽取文本漏了 TN，按定义补全即可。准确率最大的问题是：它在类别不平衡时会骗人——若 95% 的样本是负类，一个「全判负」的模型准确率就有 95%，却一个正例都没抓到（见 p139）。这也是必须同时看 F1 与 AUPRC 的原因。

🎯 不平衡时 accuracy 会被多数类撑高，不能只看它。

P129

Precision 精确率

考点

Precision = TP/（TP+FP） = 9/11 ≈ 0.81，意思是「模型说是正的里面，有多少真的是正」——分母用的是预测为正的样本。课件给了一个极端提醒：想要 100% 精确率很简单——把阈值抬到只剩分数最高的那一个正例，别让任何负例混进来；但这样召回率会很低。所以精确率不能单独看。

🎯 100% 精确率很容易（只判 1 个正例），单指标会骗人。

P130

Recall 召回率（敏感度）

考点

Recall = Sensitivity = TP/（TP+FN） = 9/10 = 0.9，意思是「真实为正的里面，模型抓回了多少」——分母是真实为正的样本。课件给了两个极端：想要 100% 召回率很容易，把阈值降到把所有样本都判正即可。它还给了操作性描述：想在 100% 召回下提高精确率，就把排名最低的正例尽量往上提；想在 100% 精确下提高召回率，就把排名最高的负例尽量往下压。

🎯 100% 召回率很容易（全判正），代价是精确率低。

P131

Specificity 特异度

考点

Specificity（负类召回率）= TN/（TN+FP） = 8/10 = 0.8，意思是「真实为负的里面，模型正确排除了多少」。它和敏感度是一对：敏感度看正类抓得全不全，特异度看负类排除得干不干净。ROC 曲线的两个轴正是这两个量（p137）。课件抽取文本把公式写成 TN/TN+FP，实际分母要加括号，别抄错。

🎯 分母是 TN+FP（负类总数），别与敏感度的 TP+FN 搞反。

P132

F1-score

考点

F1 = 2 × Precision × Recall /（Precision + Recall） = 2×0.81×0.9/(0.81+0.9) ≈ 0.857。它是精确率与召回率的调和平均（harmonic mean），特点是「两边只要有一个很低，F1 就低」，因此适合在两者之间做平衡。与算术平均的区别要会答：算术平均允许用高的一项掩盖低的一项，调和平均不允许，所以 F1 常被当作单一综合评价。

🎯 F1 是调和平均：P、R 有一个低，F1 就低。

P133

IoU 交并比

考点

进入分割与检测的指标：IoU（intersection over union，交并比）= 预测区域与真实区域的交集面积 ÷ 并集面积。两个框完全重合时 IoU = 1，完全不重叠时 = 0。它同时惩罚「偏」和「大」：框偏移会减少交集，框画太大又会增大并集。检测任务里常用一个 IoU 阈值（例如 0.5）来判定「这个框算不算检测对」。

🎯 IoU＝交集/并集；重合为 1，不重叠为 0。

P134

mIoU 与像素准确率

考点

mIoU（mean IoU）的做法很直接：先对每个类别各算一个 IoU，再对这些 IoU 取平均——这样小类别不会被大类别淹没，这是它比像素准确率更公平的原因。课件还提到另一个常用指标像素准确率（pixel accuracy）= 分类正确的像素数 ÷ 总像素数，它算起来简单，但在类别极不平衡时会被大面积类别主导。

🎯 mIoU 先按类算 IoU 再取平均；像素准确率会被大类主导。

P135

改变阈值，指标全变

考点

把阈值从 0.5 抬到 0.6，同一个模型得到新矩阵：TP=7、FP=2、FN=3、TN=8。指标随之变化：Accuracy 0.75、Precision 0.77、Recall 0.7、Specificity 0.8、F1 0.733——准确率下降、精确率上升、召回率下降。课件还给了一个关键数字：有效阈值个数 = 样本数 + 1（20 个样本 → 21 个阈值），因为阈值只需取在相邻分数之间。注意这五个指标并不是同向变化的。

🎯 阈值↑→精确率↑、召回率↓；有效阈值 = 样本数+1。

P136

阈值扫描

考点

把上一页的想法画出来：横轴是分数（0 到 1），不断移动阈值（从 0.00 扫到 1.00），每移动一次就重算一组 TP/FP/FN/TN。把所有阈值下的（敏感性、特异度）或（召回率、精确率）连成线，就得到 p137 的 ROC 与 p138 的 PRC。记住结论：单点指标依赖阈值，曲线指标把所有阈值都看一遍，所以曲线指标更全面。

🎯 单点指标依赖阈值，曲线指标把所有阈值看一遍。

P137

ROC 与 AUROC

考点

ROC 曲线以敏感度（Sensitivity = TP/LabelPos）为纵轴、特异度（Specificity = TN/LabelNeg）为横轴，阈值从 0 扫到 1 画出来。AUROC = ROC 曲线下的面积，等价说法是「随机取一个正例和一个负例，正例分数更高的概率」。三个必背点：AUC=1 完美、0.5 等于随机猜测（就是那条对角线）；AUROC 对患病率不敏感（agnostic to prevalence），所以在类别不平衡时它仍可能很好看——这正是 p140 的坑。

🎯 AUROC 对患病率不敏感：不平衡时仍可能很高，这是坑。

P138

PRC 与 AUPRC

考点

PR 曲线纵轴是精确率（Precision = TP/预测为正）、横轴是召回率（Recall = TP/真实为正）。AUPRC = PR 曲线下的面积，也可理解为「随机阈值下的期望精确率」。两个关键性质：① 阈值取 0（全判正）时 Precision = prevalence，所以 PR 曲线不会低于患病率这条水平线；② 形状上，正例被排上来时缓慢上升，负例被排得更高时精确率垂直下降而召回率不动。正例稀少时 PRC 比 ROC 更合适。

🎯 PRC 下界是患病率；正例稀少时用 AUPRC 更合适。

P139

类别不平衡

考点

类别不平衡（class imbalance）：课件给的经验症状是 患病率 prevalence < 5%（没有严格定义）。它带来两个问题：① 指标可能没有意义——模型只要永远预测多数类就能拿到很高的准确率，却没学到任何关于少数类的东西；② 学习过程可能根本不关注少数类，因为损失被多数类主导。这正是要用 AUPRC、F1、召回率而不是只看准确率的原因。

🎯 prevalence<5% 即可疑；准确率高≠学到东西。

P140

不平衡下各指标的表现

考点

逐个看指标在类别不平衡下的表现：Accuracy 会盲目预测多数类，所以它的「基线」就是患病率（永远猜负也等于 prevalence）；AUROC 只要把大多数负例打成极低分，AUC 就能保持很高，容易高估模型；AUPRC 相对更稳健，但仍存在非差分（non-differential）等问题。课件给的总结排序是：Accuracy < AUROC < AUPRC，越往后越能反映少数类的真实表现。

🎯 排序题：Accuracy < AUROC < AUPRC（不平衡下）。
